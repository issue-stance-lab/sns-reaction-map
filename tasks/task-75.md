# 課題75: 一次資料メモの年度ラベルのずれを点検する（部活動 資料I-2で発覚）

**登録日**: 2026-09-20
**状態**: 進行中（発覚した部活動メモの2行は修正済み。他テーマ・他資料の同種点検が残り）
**優先度**: 中（公開ページとX投稿には未流出。ただしメモは投稿・ページの数字の出所として
毎回参照されるため、放置すると次に使うときに誤った年度で発信する）

## 何が起きたか

2026-09-20のX投稿（部活動指導員）の準備で、`quality/research/bukatsu-chiiki-primary-sources.md`
資料I-2の数字を一次資料PDFと突き合わせたところ、**年度のラベルが1年ずれていた**。

- メモの記述（修正前）
  - 休日: 地域展開は 令和5年度 5.6%（7,121部）→ **令和7年度 10.0%（12,764部）** → 令和8年度（予定）27.8% → 令和9年度（予定）38.2%
  - 平日: 地域展開は 令和5年度 1.9%（2,373部）→ **令和7年度 2.8%（3,631部）** → 令和9年度（予定）14.3%
- 一次資料（スポーツ庁・文化庁「部活動改革の取組状況に関する調査（令和8年度調査）」
  https://www.mext.go.jp/sports/content/20260805-spt_oripara-000028257_001.pdf ）の実際の並び
  - 休日・地域展開: R5 5.6%（7,121部）／**R6 10.0%（12,764部）**／**R7 17.5%（22,357部）**／R8（予定）27.8%（35,613部）／R9（予定）38.2%（48,909部）
  - 平日・地域展開: R5 1.9%（2,373部）／**R6 2.8%（3,631部）**／**R7 4.7%（6,040部）**／R8（予定）9.7%（12,388部）／R9（予定）14.3%（18,261部）
  - 休日・地域連携（合同部活動・部活動指導員）: R5 9.0%／R6 10.5%／R7 11.6%／R8（予定）11.8%／R9（予定）11.4%
  - 平日・地域連携: R5 8.9%／R6 10.1%／R7 11.2%／R8（予定）11.6%／R9（予定）12.0%

つまりメモは、**最新の実績年（令和7年度）の値を書かず、1つ前（令和6年度）の値に令和7年度の
ラベルを付けていた**。予定値（令和8・9年度）のラベルは正しい。

原因は、グラフだけのPDFをテキスト化すると年度の軸ラベルと棒の値が別々の行に散るため、
上から順に拾うと年度と値の対応を取り違えること（確認日2026-09-07の記入時と推定）。

## 影響範囲（2026-09-20時点で確認済み）

- 誤った数字が出ている場所は**このメモの2行だけ**。`12,764` `10.0%` `3,631` を
  リポジトリ全体（archive除く）で検索し、公開HTML・`content/`・`configs/`・note下書きには無い。
- 過去のX投稿は**いずれも影響なし**。
  - 2026-09-17の部活動リプライは 休日38.2%・平日14.3%（ともに令和9年度予定）を使っており正しい。
  - 2026-09-20の部活動指導員リプライは 地域連携の実績（9.0→10.5→11.6→11.8→11.4%）を
    「1割台で横ばい」と使っており正しい。
- 修正: 2026-09-20、本課題の登録と同時にメモの該当2行を一次資料どおりに直した。

## 残っている作業

1. **同じPDF由来の他の記述の点検**（市区町村数の系列＝休日 R5 51.1%…R9 76.6%、平日 R5 40.6%…R9 46.4% など）。
   同じ読み取り方をしているため、同種のずれが他にもある可能性がある。
2. **他テーマの一次資料メモ（`quality/research/*-primary-sources.md`）のうち、
   グラフPDFから拾った数字の年度ラベル点検**。特に「年度＋割合」が複数年並ぶ記述。
3. 再発防止の検討。グラフのみのPDFから数字を拾うときは、**割合と実数（括弧内の部数）の両方を
   控え、実数÷母数で割合を検算する**（今回は 48,909÷128,000=38.2% で系列の同定ができた）。
   この手順を `.claude/skills/primary-research` 側のルールに足すかは未判断。

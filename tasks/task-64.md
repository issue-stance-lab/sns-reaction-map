# 課題64: 部活動テーマ「学習指導要領上の位置づけ」の未照合を解消する

**登録**: 2026-09-07 / **優先度**: 中 / **関連テーマ**: bukatsu-chiiki

## 何が起きたか

オーナーから「一次資料の部活動フォルダに、新しい学習指導要領について調べてあるか」と
聞かれ、確認したところ**ほぼ無かった**。

`quality/research/bukatsu-chiiki-primary-sources.md` には、スポーツ庁の
「学習指導要領における部活動・地域クラブ活動の取扱いに関する検討ワーキンググループ
（第2回）議事録」が資料D-4として入っていたが、そこから引いていたのは
**費用の話（浅野次長「300億円以上の公費負担」発言）だけ**だった。
WGの本題である「学習指導要領の中で部活動をどう位置づけ直すか」は手つかずで、
次期学習指導要領（中教審の審議）そのものは1件も入っていなかった。

そこで 2026-09-07 に第7節「学習指導要領上の位置づけ」を新設し、資料M〜Qを収集した。
**ただし本文の照合ができていない。**

第7節の冒頭と、メモ末尾の未確認リスト7番に「未照合・転記禁止」と明記済み。
`quality/research/status.yaml` の `bukatsu-chiiki.last_verified` は

## 照合の結果（2026-09-07、オーナー手元環境で実施）

**通信は問題なく通った。** URL 14本すべて `curl -sI` で200。PDFは `pdftotext` で本文化し、
国会会議録は `kokkai.ndl.go.jp/api/speech` で発言全文を取得して突き合わせた。
決着させるべき問い5つは**すべて決着した**。

1. **現行の位置づけ** — 資料Mの原文と一致を確認。新設時に「実在するか未確認」としていた
   引用（「教育課程外の学校教育活動である部活動について，教育課程との関連が図られるように
   するとともに，持続可能な運営体制が整えられるようにする」）は**原文に実在した**。
   本体条文は「教育課程外」かつ「学校教育の一環」という二重の建て付け。
2. **令和6年12月の解説一部改訂** — 通知は **6ス庁第1761号・令和6年12月25日**（PDFのURL日付
   20250116 は掲載日で発出日ではなかった）。通知本文に「学習指導要領本体に変更を加える
   ものではない」と明記。新旧対照表で「部活動は……法令上の義務として実施されるもの
   ではないことから学校の判断により実施しないこともあり」の一文が**新設**であることを確認。
3. **次期改訂で削除されるか** → **削除されない。** 一次資料3点で確定。
   ①WG第2回たたき台（令和8年3月）「基本的な事項に係る記載は、現行学習指導要領の記載を
   ベースとしつつ」／②中教審 審議まとめ素案（令和8年8月31日）に「（8）部活動・地域クラブ
   活動の示し方」の項が実在し「双方について記載することとし」と結論／
   ③**松本洋平 文部科学大臣答弁（2025-11-20 参議院文教科学委員会）**
   「部活動に関しても一定の記載を行うことが考えられる」（原文照合済み）。
   → 内田良氏の見立てが一次資料と整合。教育新聞（2022-06-17）の「削除を含めて見直す」は
   **2022年の国会会議録に該当答弁が存在しない**（末松信介文科相の「部活動」を含む発言22件を
   全件取得して確認）ため、一次資料としては採用しない。
4. **WGは何回で終わったか** — **第1回・第2回の2回のみ**。第3回以降は存在しない。
   取りまとめに当たる文書は第2回配付資料1-1「たたき台」。
5. **全面実施年度** — 割れていたのは校種を混同していたため。スケジュールPDFで確定：
   幼稚園等 令和10年度(2028)／小学校 令和12年度(2030)／**中学校 令和13年度(2031)**／
   高校 令和14年度(2032)入学生から順次・令和16年度(2034)全面実施。
   **部活動テーマで使うべきは中学校の令和13年度。** 第1回WG議事録の事務局説明とも一致。

### 副産物（第7節に書き足した事実）

WG第1回議事録に、学習指導要領における部活動記載の**変遷**が事務局説明として残っていた。
昭和33・44年＝記載なし／平成元年＝「部活動」初出／**平成10年＝記載を一旦すべて削除**／
平成20年＝独立記載が復活／平成29年＝現行。**過去に一度削除された前例がある**ことは、
「次期でも削除されるのでは」という見立てが根拠なく出たわけではないことを示す。
また、全国中学校長会側の委員が「学習指導要領上の位置づけがないと引率の根拠が失われる」
「公費で出張旅費が出ない地域がある」と述べており、位置づけ論が現場の実務に直結している。

## 判断が要る点（オーナー）

primary-research 系の作業をクラウド側（Claude Code on the web）で回すか、手元に寄せるか。
今回はっきりしたのは、**クラウド側からは省庁サイト・国会会議録に通信できず、照合ができない**
ということ。収集と下書きはクラウドでもできるが、照合だけは手元が要る。
私なら「調査は手元セッションで行う」と決めて、`primary-research` スキルに一文書き足す
（＝ルールは検査か手順書に書かないと守られない）。

## 影響範囲

- この論点（部活動が制度上どこに属するか）は、地域移行の「誰の責任か」という対立の根っこ。

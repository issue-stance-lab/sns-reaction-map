# 課題64: 部活動テーマ「学習指導要領上の位置づけ」の未照合を解消する

**登録**: 2026-09-07 / **優先度**: 中 / **関連テーマ**: bukatsu-chiiki

## 何が起きたか

オーナーから「一次資料の部活動フォルダに、新しい学習指導要領について調べてあるか」と
聞かれ、確認したところ**ほぼ無かった**。

`quality/research/bukatsu-chiiki-primary-sources.md` には、スポーツ庁の
「学習指導要領における部活動・地域クラブ活動の取扱いに関する検討ワーキンググループ
（第2回）議事録」が資料D-4として入っていたが、そこから引いていたのは
**費用の話（浅野次長「300億円以上の公費負担」発言）だけ**だった。
WGの本題である「学習指導要領の中で部活動をどう位置づけ直すか」は手つかずで、
次期学習指導要領（中教審の審議）そのものは1件も入っていなかった。

そこで 2026-09-07 に第7節「学習指導要領上の位置づけ」を新設し、資料M〜Qを収集した。
**ただし本文の照合ができていない。**

## 未解決の中身

調査したのが Claude Code on the web のリモートコンテナで、ネットワークポリシーにより
`www.mext.go.jp` / `www.bunka.go.jp` / `kokkai.ndl.go.jp` / `laws.e-gov.go.jp` への
通信がすべて遮断されていた（`curl` は CONNECT 403、WebFetch は EGRESS_BLOCKED、
プロキシの `recentRelayFailures` にも記録された）。
そのため primary-research スキル手順4の機械照合（本文突き合わせ・`curl -sI` の200確認）を
1本も通せず、第7節は全体が検索結果スニペット由来のまま残っている。

第7節の冒頭と、メモ末尾の未確認リスト7番に「未照合・転記禁止」と明記済み。
`quality/research/status.yaml` の `bukatsu-chiiki.last_verified` は
**2026-08-31 のまま据え置いた**（照合していないので進めてはいけない）。

## 決着させるべき問い

1. 現行の総則・解説で部活動はどう書かれているか（原文の引用を確定する）
2. 令和6年12月の解説一部改訂で何がどう変わったか（新旧対照表の条文差分）
3. 次期学習指導要領で部活動規定は削除されるのか維持されるのか
   （審議まとめ本文＋文科相答弁の原文。教育新聞は「削除を含めて見直す方針」、
   内田良氏の記事は「次期でも学校教育の一環のまま残る見込み」とし、見立てが割れている）
4. スポーツ庁WGは第2回で終わりか、取りまとめ文書はあるか
5. 次期学習指導要領の全面実施年度（検索結果内で令和10年度と2029年度に割れていた）

## 次にすること

**外部サイトに接続できる環境で作業する。** オーナーの手元のパソコンで動かすセッションなら
通信制限がないはずなので、そちらで第7節の資料M〜Qを照合する。
照合が終わったら `status.yaml` の `last_verified` を当日に更新し、
`quality/research/README.md` の状態欄から「未照合」の注記を消す。

**照合が終わるまで、第7節の内容をページ・note・Xに転記しないこと。**

## 影響範囲

- この論点（部活動が制度上どこに属するか）は、地域移行の「誰の責任か」という対立の根っこ。
  note第5回以降やページの論点カードで使う価値が高い一方、いま書くと未照合の孫引きになる。
- 環境依存の問題でもある。**クラウド側のセッションでは一次資料の照合作業ができない**ことが
  今回はっきりした。primary-research 系の作業は手元環境に寄せる判断が要る（オーナー判断）。

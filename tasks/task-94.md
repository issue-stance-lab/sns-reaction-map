## 結論

憲法改正ページは、サイト内で最初に検索流入を伸ばす候補として妥当。ページ自体はGoogleに登録済みで、
新ドメインのSearch Consoleで確認できた表示13回のうち8回を占める。一方、クリックは0であり、
現行のタイトル・冒頭は「論点を見たい人」には合うが、検索で多い「何が変わる」「わかりやすく」
「メリット・デメリット」「賛成・反対の理由」に最初の画面で短く答え切れていない。

最初の実装は新規記事の量産ではなく、**既存の登録済みページの冒頭に、現在の提案内容・
期待される効果・懸念・手続きを事実と意見に分けた要約を置き、FAQを追加すること**。現行ページが持つ
一次資料、SNS意見1,756件、賛否両側の理由という独自資産を、検索者が理解しやすい順へつなぎ直した。

## 現行ページの棚卸し

対象: `docs/constitutional-amendment-reaction-map.html`（2026-09-27時点）。

- title: `憲法改正は何が論点？9条・緊急事態条項と賛否｜SNS反応まっぷ`
- description: `憲法改正をめぐるSNS投稿を、9条、緊急事態条項、国民投票、情報環境など6つの論点に分類し、賛否と判断理由を整理します。`
- H1はtitleと同じ
- 主な順序: 議論の中心 → 立場内訳 → 背景・経緯 → 現行と提案の確認 → 山なみ → 各論点 →
  一次資料クイズ → 投稿例 → 投票 → 授業・ディベート → 作り方
- FAQ専用節とFAQ構造化データはない

### 強み

- 収集2,003件・意見1,756件を、6論点・4立場・理由区分で読める
- SNSの代表投稿、一次資料との照合、資料にしかない話を同じページで往復できる
- 9条、緊急事態条項、国民投票、情報環境まで現行の需要群をすでに含む
- 賛成・反対だけでなく、手続き重視・中立も分けている
- 現行／提案、事実／意見、成立済み／議論中を区別する土台がある

### 足りない入口

- 「現時点で憲法そのものは改正されていない」「単一の確定案はない」が冒頭で即答されない
- 「何が変わる候補か」を3〜4項目で一覧できず、詳しい背景まで読まないと分からない
- 検索者の言うメリット・デメリットを、中立的な「期待される効果／懸念・確認点」として対比していない
- 賛成理由・反対理由への直接アンカーがなく、検索結果から該当箇所へ着地しにくい
- よくある質問がなく、「国民投票法改正」と「憲法改正」の違いなどを短く拾えない
- titleは論点中心で、「何が変わる」という最も直接的な疑問との一致が弱い

## 事実説明と意見整理の境界

### 事実として書けること

- 憲法96条の発議・国民投票要件
- 国民投票法の投票期日、有効投票の過半数、最低投票率の規定がないこと
- 2026年国民投票法改正の成立内容と施行日
- 自民党の4項目は自民党の提案であり、成立した憲法条文ではないこと
- 国会資料のイメージ案は議論の素材で、全会派合意の確定案ではないこと
- 日本国憲法は2026-09-27時点で改正されていないこと
- 収集したSNS標本の件数・期間・分類方法

### 意見として主語を付けること

- 自衛隊明記で違憲論が解消する／活動範囲が広がるという評価
- 緊急事態条項が迅速な対応に必要／権力集中の危険があるという評価
- 9条が抑止力を弱める／平和の歯止めになっているという評価
- 現行憲法が時代に合わない／変える必要がないという評価

### 更新手順

1. 国会会議録・審査会資料・法令・政党公式文書で事実を確認する
2. `成立済み` `国会で審議中` `議論用資料` `政党提案`をラベルで分ける
3. 冒頭の「先に結論」と更新日だけ先に直し、詳細は該当アンカーへ追記する
4. SNS反応は通常のデータ更新手順で収集し、検索向け本文へ手集計を直書きしない
5. titleは恒久語を維持し、人名・一時的ニュース語を毎回入れ替えない
6. X・noteはニュースの疑問から該当アンカーへ送る。URLには計測用UTMを付ける
7. 変更後にSearch Consoleでクエリ別表示を30日観察する

速報競争はしない。一次資料が出た当日〜翌営業日に「何が決まり、何がまだ決まっていないか」を

## 30日間のKPIと判定条件

計測開始日は本文実装・公開・Search Console確認が済んだ日。今回の調査日からは数えない。

### 記録するもの

- Search Console: ページの表示、クリック、CTR、平均掲載順位
- Search Console: 第1〜3群のクエリ別表示とクリック
- Search Console: ページが登録済みのままか、サイト全体の登録ページ数
- GA4: 検索流入の入口回数とエンゲージメント（取得できる範囲）
- X / note: UTM別の流入、投稿表示、noteビュー
- Googleの外部リンク認識数（0から変化したか）

### 30日判定

| 判定 | 条件 | 次の対応 |
|---|---|---|
| 採用 | 表示20以上かつ自然検索クリック1以上 | 入口改善を維持し、9条か国民投票の独立記事を検討 |
| 強い採用 | 表示30以上かつCTR3%以上 | 同じ型を他の登録済みテーマへ展開 |
| 改善継続 | 表示10以上・クリック0、または平均順位11〜30 | title/descriptionだけを1回見直し、さらに30日観察 |
| 判定不能 | 表示10未満で、登録10/18未満または外部リンク認識0のまま | 内容を失敗扱いせず、課題15・55の基盤改善後に再判定 |
| 差し戻し候補 | 比較可能な前30日より表示が30%以上減り、登録・ニュース要因で説明できない | 変更箇所を分けて原因確認。自動では戻さない |

# 課題98: 部活動の地域移行テーマの検索流入施策を設計・検証する

## 状態

進行中（2026-09-27着手）。調査・施策設計・サイト実装を同日に本番公開し、30日間の効果計測を開始した。広告配信は行っていない。

## 目的

「部活動の地域移行」を調べる人がどの場面で、どの言葉を使い、何を知りたいかを整理し、
既存のSNS反応マップへ無料で検索流入を増やす施策を決める。

## 現状（2026-09-27時点、オーナー共有値）

- サイト18ページ中、Google登録済み5ページ、「検出 - インデックス未登録」12ページ。
- Search Console過去3か月は表示13・クリック1。Googleが認識する外部リンクは0件。
- キーワードプランナーでは「部活動 地域移行」が月間1,000〜1万、競合性は低。
- 現時点で対象ページの検索表示は確認できず、インデックス未登録の可能性が高い。

## 調査方法

`needs-research` スキルの順序で進める。

1. 広く集める: Googleサジェスト、Google Trends、キーワードプランナーから関連語を機械的に収集する。
2. 数字でふるいにかける: 検索量・競合性・5年推移・既存ページとの適合度で優先群を決める。
3. 深く調べる: 通常検索、知恵袋、一次資料、上位ページから検索意図・読者・不足情報を確認する。
4. 小さく検証する: 無料導線と30日KPIを定義し、実装前に成功・継続・見直しの判定条件を置く。

困っている人、情報を探す人、検索のきっかけを分ける。制度上の事実、未決定事項、SNS上の意見も分けて記録する。
Amazon・ココナラは無料の情報サイト集客と購買意図が合わないため対象外とし、その理由を調査資料に残す。

## 結論・根拠・次の実装候補（2026-09-27調査完了）

### 結論

最初に実装するなら、新しい記事を増やすより、既存の部活動ページ冒頭へ
「部活動の地域展開（旧・地域移行）はいつから、誰が対象で、何が変わるか」を短く答える検索入口を追加する。

既存ページは1,401件のSNS反応、7論点、一次資料との照合があり、一般的な制度解説にはない強みがある。
一方、検索上位が先に答える「いつから」「地域展開との違い」「高校も対象か」「費用・送迎」は、
現在のタイトル・冒頭見出しでは直接答えておらず、情報が本文に埋もれている。

### 数字の根拠

- Googleサジェスト: 必須7語から320語へ機械展開。
- キーワードプランナー: 中心語は月1,000～1万、競合性低。
- 月100～1,000: `いつから`、`問題点`、`メリット デメリット`、`指導者 報酬`、`高校`。
- `高校`は直近3か月+900%、`地域展開との違い`は前年比で新規、`失敗`は前年比+900%。
- Google Trends 5年: 中心語は2022年以降継続。`地域展開`は2025年以降上昇。
- 知恵袋: 108件取得、直接関連53件。教員負担・兼職兼業24、受け皿・指導者18、開始時期・対象17（複数分類）。

広告未出稿アカウントのため検索数は幅表示、入札単価は取得できなかった。Amazon・ココナラは、
物販・依頼購入の行動と無料情報ページの検索意図が対応しないため対象外。Redditも日本の制度・自治体運用の調査には適さないため対象外とした。

### 狙うキーワード群

1. `部活動 地域移行`＋`部活動 地域展開`＋`違い`
2. `いつから`＋`休日`＋`平日`＋`高校`
3. `費用`＋`保護者負担`＋`送迎`
4. `問題点`＋`メリット デメリット`
5. `指導者`＋`報酬`＋`教員`

### 実装候補

- H1直下に200～350字の結論、2026～2031年度の短いロードマップ、対象、費用の自治体差を置く。
- H2に「地域移行と地域展開の違い」「いつから」「高校・私立・平日」「費用・送迎」を追加する。
- FAQは「2026年度から全国一律で廃止か」「月謝はいくらか」「教員は指導できるか」等を置く。
- 事実、未決定、SNS意見を見た目でも分ける。新版ガイドラインとの未照合注記は、整合確認後に更新する。

## ローカル実装（2026-09-27）

- H1と説明文を「地域展開／いつから／費用／問題点」に合わせて更新した。
- H1直後に、全国一律廃止ではないこと、2026〜2031年度、休日・平日の違い、対象、自治体差をまとめた入口を追加した。
- 「休日／平日」の2本のロードマップ、確定・自治体ごと・未決定の表示、既存本文への4導線を追加した。
- 全国共通の制度回答の直下に、保護者・生徒・教員・地域指導者の4視点を統合した。視点を選ぶと「全国で確定／自治体ごと／未決定」と次の確認事項が切り替わる。
- 4視点は投票やSNS投稿者属性の絞り込みではないことを近接表示し、選択を `bukatsu_role_view` で計測できるようにした。
- 4視点のタブへ、ImageGenで作成した家庭・生徒・学校・地域の背景画像を追加した。画像内に文字や人物は入れず、UIのラベルを前面に保ち、スマホでは4視点を2×2で同時表示する。
- 地域確認を6項目の質問ツールとして再表示した。項目を選ぶと質問文が切り替わり、「確認できた／まだ分からない」の整理と質問文のコピーができる。確認状態は端末へ保存しない。
- 既存のSNS反応マップ、1,401件のデータ、山の操作処理は変更していないことを回帰テストで固定した。
- 6問のFAQと同内容のFAQ構造化データを追加した。
- 2025年12月版ガイドラインとの未照合注記を解消し、一次資料台帳と連動表示を2026-09-27確認内容へ更新した。
- PC幅1280px・スマホ幅500pxの全ページ画像、4視点の実操作、FAQ、既存アンカー、生成の再実行、テーマページ検査を確認した。

# TASK_BOARD の書き方のルール

> `TASK_BOARD.md` の索引を小さく保つためのルールです。
> 新しい課題を登録・更新するときだけ参照してください。

2026-09-03 時点で `TASK_BOARD.md` は 1,930行・約9.5万文字あり、実際の作業に必要なのはその1割以下でした。
このため、索引には必要最小限の情報だけを載せ、詳細は別ファイルに分ける運用にしています。

- **索引に書くのは6欄だけ。** `状態` `優先度` `期限` `次にすること` `判断待ち` `関連テーマ`。
  必須は `状態` と `次にすること` と `詳細`。ほかは無ければ省く
- **1欄1行。120文字以内。** 経緯・実測ログ・レビュー指摘・手順は詳細ファイルへ書く
- **`状態` は区分から書き出す。** `未着手` / `進行中` / `保留` / `完了` のどれかで始める
  （管理ダッシュボードがこの書き出しで区分を判定している）
- **完了したら、その日のうちにアーカイブへ移す。** 索引から行を消し、
  `tasks/task-N.md` を `archive/tasks/` へ移し、`archive/TASK_BOARD_ARCHIVE.md` に1行足す。
  残作業があるものは完了にせず `進行中` のままにする
- **新しい課題は `tasks/task-{番号}.md` を作ってから索引に足す。**
- 検査: `python3 scripts/verify_task_board.py`（索引の大きさ・欄の長さ・詳細ファイルの有無を見る）

## 運用ルール

- ハブAI（Claude Code）は毎セッション `OPERATIONS.md` に従って動く
- ワーカーAIは `configs/prompts/` のプロンプトに従って作業する
- ブランチ運用: `task/{theme}-{工程}` 形式。main直接コミット禁止
- 保護タグ: GA4(`G-K10S4YCZFH`) / AdSense(`ca-pub-2542211932832864`) / Supabase / OGP

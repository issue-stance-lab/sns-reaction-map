# 課題107: 投票サーバーに接続できない

**登録**: 2026-10-31。オーナーから依頼された公開サイト全体点検で発見。
**状態**: 進行中。接続障害は復旧済み。実票を送信するブラウザ通し確認のみ未実施。
**優先度**: 最優先。

## 確認したこと

- 公開中の`vote-config.js?v=1`が使う接続先は`qslrlprzoucrlptnhsmi.supabase.co`。
- 手元の名前解決に失敗。Google Public DNSとCloudflareのDNS-over-HTTPS照会でも、両方がStatus 3（NXDOMAIN、該当するサーバー名なし）、Answerなしを返した。
- 公開中の部活動ページから、共通クライアント`VoteStore.getCounts('bukatsu-chiiki')`を実行すると、remote=trueで`TypeError: Failed to fetch`。
- KPI一括取得もSupabaseの取得で終了。GA4・Search Consoleは個別に取得できた。
- `vote-store.js`の集計GETと投票POSTは同じサーバー名を使うため、全テーマの投票にも影響する可能性が高い。

投票は送信していない。障害の開始日、プロジェクトの停止・削除・URLの設定違いのどれか、既存投票の残存は未確認。原因を推測して新しいプロジェクトを作ったり、既存データを消したりしない。

## 次にすること

1. Supabaseの管理画面でプロジェクトの状態と接続先を確認する。
2. 既存の投票データが残っているか確認する。
3. 集計の読み取りを復旧し、公開ページの共通クライアントからも確認する。
4. 設定・公開ファイルの変更が必要なら候補を用意する。公開変更、支出・契約変更、データ削除は既存の承認ルールに従う。
5. 承認済みの試験で送信・保存・重複防止を確認する。試験票の扱いを決めてから送信する。
6. 管理画面で、設定ファイルの存在と投票サービスの稼働状態を区別する。接続監視を追加する場合はGETだけを使う。

## 2026-10-31 復旧調査の続き

オーナーから原因調査と復旧の指示を受領。

- 公開設定と手元の`.env`の接続URLは一致。設定間の食い違いは見つからなかった。
- Google・CloudflareのDNSで再確認してもNXDOMAINが継続。
- 両方のChromeプロファイルでSupabase管理画面へのログインが必要だった。既存のGitHubログインへの導線を開き、オーナーにログインを依頼した。
- 利用可能なSupabase管理用CLI認証は見つからず、公開キーだけではプロジェクトの状態確認・再開はできない。
- 無料プランの低利用による自動停止は候補だが、管理画面で未確認のため原因とは断定しない。公式説明: https://supabase.com/docs/guides/platform/free-project-pausing

次は、ログイン後に該当プロジェクトの状態・既存データを確認し、停止中なら既存プロジェクトを再開する。新規作成やデータ削除は行っていない。


## 2026-10-31 原因確定・接続復旧

管理画面で既存のsns-reaction-mapプロジェクトがPaused（停止中）だったと確認。データ保全の表示を確認したうえで、オーナーの復旧指示に基づきResumeを実行した。復元中の一時的なcount_failed、テーブル未作成、接続終了は、復元完了後に解消。Healthyになった。

無料プランの低利用による自動停止は制度上の候補だが、停止操作・自動停止の区別と停止日時は未特定。確定原因はプロジェクト停止。新規プロジェクト作成、料金変更、スキーマ変更、データ削除、公開ファイル変更は行っていない。

確認結果:
- 全受け付けトピックの集計GETが成功。票のある10トピックの合計は26票。過去に記録した25票を上書きで復元したのではなく、現在の実集計。
- SQLでpublic.votes全体35行を確認。公開APIの対象外の過去トピックなども含むため、26票とは集計範囲が異なる。
- 保存関数をトランザクション内で試験。初回true・同じ識別子の再送falseを例外付きで検証し成功。ROLLBACK後の35行を確認し、試験票は残していない。
- 本番Origin付きOPTIONSは200、Originを許可。POSTの不正選択肢は400 invalid_choice。送信経路と入力検証を確認。
- 公開ページの通常表示を確認。実際の意見として票を加えるブラウザの通し送信は未実施で、完全な通し確認済みとはしない。
- 管理ダッシュボードの実測値キャッシュを再取得。

次は実利用時の投票完了表示と集計増分を確認して完了整理する。無料プランには再停止の可能性があるが、有料化や新しい自動監視の登録は行っていない。

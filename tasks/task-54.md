**目的**: テーマごとに雑多な情報を縦に並べるページから、読者が議論の全体像を回し、論点へ着陸し、

**照合レイヤー（2026-09-01 追加）**: 惑星の陸地は「SNSで何が語られたか」で、これは収集と分類の仕組みが
あれば再現できる。独自性はそこには無い。海面より下に、**人が一次資料を読まないと出てこない情報**だけを置く。

- **沈んだ大陸** — 一次資料では争点なのに、収集した投稿にほとんど無い論点
- **地下水脈** — 対立する立場が共有している具体的な懸念（両側の代表投稿を並べて示す）

「無いもの」は集計できない。人が資料を読んで初めて分かる。この非対称が「AIが集めて分類しただけ」を
構造的に成立させなくする。仕様は設計書 3.3、書き方の基準は 3.3.2（重要度の名指しはしない）。

**変えない意味**:
- 球体全体 = 1テーマ
- 大陸・島 = 論点
- 面積 = その論点に分類された意見数
- 色 = その論点内のスタンス分布（テーマ固有ラベルを使い、単純な赤青へ固定しない）
- 標高 = AI分類から再現可能な「強い表現の割合」。正しさ・重要度・世論の熱量とは呼ばない
- 大陸の位置 = 初版では見やすさのための配置。論点同士の近さを意味しない

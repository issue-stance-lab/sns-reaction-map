# 課題59: 複数テーマ更新を1つの公開候補として統合する


**状態**: 未着手（2026-09-01に実運用で検出）
**優先度**: 高
**判断待ち**: なし
**関連テーマ**: 全テーマのデータ更新・公開

**概要**: `refresh_topic.py --prepare-promotion` は、テーマ固有の正典とページだけでなく、トップページ、公開データcatalog、全テーマの公開JSON、サイトマップ、テーマ台帳も候補に含める。複数テーマを同日に個別に候補化すると、後から適用した候補が先に適用したテーマの全体集計を古い値へ戻す。

**やること**:

1. 複数の `run-id` を指定して、テーマ固有の正典・検証データ・ページを1つの候補ツリーへ統合する機能を追加する
2. 統合後に公開JSON、catalog、トップ、SEO、sitemapを一度だけ再生成する
3. 統合候補のmanifestに全対象テーマ・run-id・ハッシュを記録し、個別候補の混在適用を拒否する
4. 3テーマ同時更新の自動テストを追加し、どの適用順でも数値が巻き戻らないことを検査する

**完了条件**: 同日複数テーマの収集回を1つの承認・公開単位として候補化でき、個別候補の順次適用では公開が停止する。

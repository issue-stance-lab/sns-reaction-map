# 課題54 段階7 レビューと修正（2026-09-04）

段階7（部活動ページの試作）を実測でレビューし、**止めるべき3件・直しておきたい4件**を修正した。
対象は `4780a01`（段階7）。作業ツリーは `task/task54-stage7-fix`。

## 直したこと

### 1. フォールバックの数字が手書きで、正典と食い違っていた

テンプレートに件数と割合が直接書かれており、**同じページの中で数字が2通り**になっていた。

| 表示 | 手書き（フォールバック） | 正典から生成（3D版） |
|---|---|---|
| 教員の働き方の割合 | 28.5% | 28.4%（`share_pct`） |
| 強い表現の割合 | 27.9% | 26.8%（`high_adjusted_pct`） |

`quality/prototypes/README.md` の「HTMLには数字が1つも書かれていない」と、
ページ本文の「数字はすべて `build_planet_data.py` が正典から数え直したもの」が、
どちらも事実でなくなっていた。

**対応**: テンプレートから手書きのフォールバックを外し、`<!--__FALLBACK__-->` の差し込み口にした。
`build_planet_data.py` の `static_fallback()` が data から組み立てる。
中心の問い・注意書き・見かた（`<!--__QUESTION__-->` / `<!--__CAUTION__-->` / `<!--__META__-->`）も
同じく生成側へ移し、これらを書いていたJSは削除した（出所を1つにするため）。

### 2. JavaScriptを切るとフォールバックが出なかった

フォールバックは `style="display:none"` で隠され、JSが外す作りだった。
JS無効時に読める本文は**517文字**（見出しと注意書きだけ）で、論点一覧も空だった。
完了条件「WebGLまたはJavaScriptが使えなくても、論点・比率・理由・一次資料・編集整理を読める」を満たしていない。

**対応**: 逆にした。フォールバックを既定で表示し、canvas 2D が使えたときだけ
`<html>` に `planet-live` を付けて隠す。JSが動かなければクラスが付かないので静的表示が残る。
主処理は try/catch で囲み、描画に失敗したらクラスを外して静的表示へ戻す。
**JS無効時に読める本文は 517 → 4,491文字**、一次資料のリンク13本を含む。

### 3. フォールバックの論点リンク7本のうち6本がリンク切れだった

`#panel-seido-fb` など、飛び先の `id` が存在しないリンクが6本並んでいた。
課題文書には「未実装」と書かれていたが、実際には押しても何も起きない状態だった。

**対応**: 7論点すべてのパネルを生成する。ページ内リンク14本すべてに飛び先がある。

### 4. 生成物が再生成で一致しなかった

`4780a01` は planet JSON の `weights` を末尾桁だけ書き換えていた（`...316829` → `...316831`）。
再生成すると1つ前の版に戻る。原因は `fit_weights` の行列積で足す順序が変わり、
最後の1〜2桁が動くこと。同一プロセス内の2回生成は差分0でも、成果物は再現しない。
このままでは課題34の再生成可能性と、段階10・11の `docs/` 差分0が崩れる。

**対応**: `stabilize()` で書き出し前に小数12桁へ丸める。表示する値はすべて小数2桁までなので
見た目は変わらない。ゆらぎの幅は約 1e-17 で、丸めの桁との差は5桁ある。

### 5. フォールバックの色がテーマ固有の立場名でCSSに直書きされていた

`.continent[data-stance="移行支持"]` のように部活動の立場名で色を決めていた。
テンプレートは10テーマ共通なので、他テーマでは**どのルールにも当たらず無色**になる。

**対応**: 色は data の `stances[].color` からインライン指定する。
文字色は背景の明るさから `text_on()` が選ぶ。

### 6. 「high率」という内部語がフォールバックに出ていた

3D版は「山の高さ：強い表現」と言い換えているのに、フォールバックは「表現の強さ（high率）」だった。
完了条件「公開ページに内部のAI判定理由を出さない」に触れる。

**対応**: 生成側の文言に統一した。

### 7. WebGLの有無を見ていたが、惑星は canvas 2D で描いている

`planet-prototype.template.html` の描画は `getContext("2d")`。WebGLは一度も使っていない。
「WebGL非対応」を判定条件にしていたため、**2Dは描けるがWebGLが無い端末**では
正常に描ける惑星を隠してフォールバックへ落としていた。

**対応**: 判定を canvas 2D の可否へ変えた。

## 検証結果

着手前にバックアップから不足していた非公開正典・更新回とペルソナを復元。
変更前の通常生成・潮目の再挿入を2回行って同一になること、既存テーマ検査、数値出典166/166を先に確認した。
新規収集・再分類はしていない。
片付け前には、作業ツリーの正典・関連JSONとペルソナが共有ツリーと全件一致し、独自の非公開データがないことも確認した。

| 確認 | 結果 |
|---|---|
| 実正典による全体再生成と潮目 | 同じ入力で2回生成し、HTMLがバイト単位で一致 |
| 部分更新 | 5つの部分更新オプション＋山だけの更新をそれぞれ2回実行。各回で一致し接続検査も合格 |
| 編集情報・分析メモ・授業節 | 実際の適用処理を2回実行して一致。連動処理と本文が残る |
| IDと欠落検査 | 順位・表示名・立場配列の順序が変わっても対応維持。所属欄からの投稿・出典欠落、接続表やJSの欠落は検査で停止 |
| 他9テーマ | 変更前と変更後の山の再生成を実データで比較し、全9テーマでバイト一致 |
| 標準検査 | `run_public_checks.py` 合格。連動候補を対象とするテーマ検査・ページ構造・文体・数値出典も合格（167/167、NG 0） |
| PC・スマホ | Chromiumの1280px/375pxで操作。バー→山・山→バーを確認。横はみ出し・JavaScriptエラーなし |
| 実数 | 条件付きの対象範囲331件、慎重の効果403件が表示データと一致 |
| 再選択 | 同じ論点をもう一度開いても「論点全体の内容」の注記が1つだけ残る |
| JavaScriptなし | 375pxで7論点・資料6件・投稿14件が残り、本文が読める。横はみ出しなし |
| 通信 | ブラウザ検査は外部通信を遮断。閲覧切替による投票操作・立場の分析イベント送信なし |

ブラウザ検査は `tests/test_consumption_tax_connected_browser.cjs`。ローカル候補だけを受け付ける。
公開データだけの検査は `tests/test_consumption_tax_connected.py`。
非公開正典を要する実更新検査は `tests/test_consumption_tax_connected_refresh.py` とし、
公開CIの対象外にする理由を `scripts/run_public_checks.py` へ明記した。正典がない場合に検査を成功扱いにはしない。

再生成の実検査で、山の見出しに数値がないため公開数値同期が失敗することと、投稿欄の部分更新で空行が増えることを検出。
共通仕上げで数値見出しと区切りの空行を正規化し、繰り返しても同じ結果にした。

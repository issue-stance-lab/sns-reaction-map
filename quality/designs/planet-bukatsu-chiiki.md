## 3. 面積の式

```
raw_i   = 件数_i / 993 * 100
area_i  = max(raw_i, 2.5)                    # 最小面積の床
超過分は床に達していない大陸から、面積比で按分して差し引く
```

- 床を2.5%にする理由: 地域格差は9件（0.9%）で、比例のままだと球面上でクリックも視認もできない。
- 床を使った大陸には凡例と着陸パネルに「面積は最小表示に拡大しています。実件数は9件」と明示する。
- 面積が実比率と一致しない大陸が1つでもある回は、凡例の注記を機械的に出す（手書きしない）。

## 4. 色

赤=反対／青=賛成は使わない。4立場に固有色を割り当て、色相・明度の両方で区別する。

| 立場 | 色 | 明度の目安 |
|---|---|---|
| 移行支持 | ティール `#2F8F83` | 中 |
| 慎重・反対 | 紫 `#7D5BA6` | 暗 |
| 条件付き・改善要求 | 黄土 `#D9A520` | 明 |
| 中立・情報 | 灰 `#8B9199` | 中（低彩度） |

大陸の色 = 最多立場の色。彩度 = その立場の占有率（純度）を 40%〜100% へ写す。
純度が低い大陸ほど白っぽくなり、「割れている論点」だと色だけで分かる。

色は要約でしかないので、**着陸パネルには必ず4立場すべての分割帯と実件数を出す**。
色覚特性に依存しないよう、分割帯には立場名のラベルを直接置く。

## 5. 標高

標高は「強い表現（intensity=high）の投稿が占める割合」だけを表す。正しさ・重要度・支持率ではない。

```
p0 = 0.219                      # 993件全体の high 率
k  = 50                         # 小標本の抑制係数
p_i = (high_i + k * p0) / (件数_i + k)
標高_i = 4.00 * p_i / max(p)    # 半径に対する % 、上限4%
```

- 地域格差の high 実測は66.7%だが n=9。抑制後28.7%に収まり、他の大陸と極端な差にならない。
- 標高は面積と独立。投稿数は面積で表しているので二重計上しない。
- この式が他テーマで再現できない場合は、上位設計どおり**標高を0にして公開する**。
  見た目のために推測値を入れない。

## 6. 固定するもの

- `issue_id` は既存ページのカウンタIDを引き継ぐ（`bukatsu-chiiki-kyoin` など）。
  URLアンカーも同じ文字列にし、note・Xからの直リンクを壊さない。
- **投票の論点の並び順は現行のまま変えない。** 投票は論点の番号で保存されており、
  並べ替えると過去の投票の意味が変わる。現行順は
  費用・家庭負担 / 受け皿・指導者 / 教員の働き方 / 教育的意義・機会 / 地域格差 /
  制度・移行プロセス / その他・わからない の7つ。
  惑星の**表示順（件数順）と投票の保存順は別物として扱う**。
- 大陸の座標と形状seedは `issue_id` から決定的に導く。更新で件数が変わっても大陸は移動しない。
  位置は見やすさのための配置であり、論点同士の近さを意味しないと凡例に書く。

## 7. 画面

1. タイトル、中心の問い、収集期間、サンプル注意（常時表示）
2. 惑星（最初の主要コンテンツ）
3. 着陸パネル

7. 関連テーマ

現行ページの「注目ポイント」「論点アリーナ」「世論の潮目」「詳細表」は、そのまま残さず
着陸パネルと横断整理へ統合する。同じ数字を複数箇所へ手書きしない。

### 着陸パネルに入れるもの（論点ごと）

- 件数と母数（例: 283件 / 意見993件中28.5%）
- 4立場の分割帯と実件数
- 中心の問い、含める／含めない境界
- 代表的な理由（立場ごと。賛否の機械的な鏡像にしない）
- その立場が守ろうとしている価値
- 一次資料へのリンク
- まだ分かっていないこと
- 表現の強さの値と定義へのリンク

### 横断整理（惑星全体）

現行データから言える横断的な発見を、編集部の文章として置く。例として次を検討する
（実装時に本文を確定する。ここでは論点の切り口だけを決める）。

- 「教員の働き方」では移行支持が58%と多いが、「教育的意義・機会」では慎重・反対が49%で逆転する。
  同じ人が反対しているのではなく、**論点が変わると賛否が入れ替わる**構造である。
- 「費用・家庭負担」は慎重・反対47%＋条件付き31%で、無条件の支持が18件しかない。
  お金の話になると賛成側も条件を付ける。
- 「地域格差」は9件しかないが、そのうち8件が慎重・反対。件数が少ない＝重要でない、ではない。
  収集した投稿の中で語られていないだけであることを明記する。

## 8. 3Dが使えない場合

初期HTMLに7論点の名前・件数・比率・4立場内訳・要旨・一次資料リンクを持たせる。
WebGL失敗、JavaScript無効、キーボード操作のいずれでも同じ内容へ到達できる。
惑星は拡張表示であって、HTMLの代わりではない。

## 9. note・Xとの接続

- note第1回〜第4回から、該当論点のアンカーへ直接着陸できるようにする。
- note記事に書いた数値は当時の `snapshot_id` の値であり、Websiteの現行値と混ぜない。
- X の流入投稿は UTM を維持したまま論点アンカーへ送れるようにする。

## 10. 検査（この構想に対応する分）

- 生成器の出力と第2節の表（件数・面積・色・標高）が完全一致する
- 同じ入力で2回生成した差分が0
- 投票の論点順が現行と一致する（並べ替えを検知したら失敗させる）
- 面積の床を使った大陸に注記が出ている
- 着陸パネルに4立場すべての実件数がある
- 375px で横スクロールなし、キーボードだけで7論点と「全体へ戻る」へ到達できる
- 公開本文にAIの信頼度・分類理由・内部指示が出ていない

## 11. まだ決まっていないこと

1. **代表投稿が未確認。** 現行993意見の中に存在することを1件ずつ確かめるまで、
   着陸パネルへ代表投稿を載せない。旧スナップショットからの流用は禁止。
2. **一次資料との突き合わせが未実装のテーマ。** 部活地域移行は課題15-Bの未実装4テーマの1つ。
   着陸パネルの一次資料欄をどこまで埋められるかは、その作業の結果で決まる。
3. 「その他」を大陸として見せるか、球の裏側の海域として見せるか。
   分類の限界を隠さない方針は決まっているが、表現は未定。
4. 配色の最終確定（色覚特性の検証を通してから）。

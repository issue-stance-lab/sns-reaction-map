# 課題77 — 消費税テーマの内容と配置をつなぎ直す表示案

作成日: 2026-09-22
状態: 公開画面・生成済みHTML・公開集計データを確認したうえでの会話内試作。本番への適用・公開はしていない。

## 結論

**立場を選ぶ → 論点の山を選ぶ → その論点の理由・投稿例・制度・資料を同じ場所で読む**、という流れにする。
冒頭に新しい質問は追加しない。今回の案は、山の動きだけを試した前の例を、実際の掲載内容に沿って組み直したもの。

動かすのは意味が変わる部分に限る。立場を変えると件数・山の幅と高さが変わり、論点を変えると対応する内容が切り替わる。
文字を常時動かす演出は使わない。長い原文・出典の詳細は、短い要旨からその場で展開できる。

## 確認した現行の並びと切れ目

[消費税テーマの公開ページ](https://sns-reaction-map.jp/consumption-tax-cut-reaction-map.html)をブラウザで操作し、以下の順序を確認した。

| 現行の場所 | 掲載内容 | 今回の扱い |
|---|---|---|
| 冒頭 | タイトル、中心の問い、画像、立場のバー・4つの選択 | 維持し、選択をマップの表示にも共通で使う |
| マップより前 | 調査条件、制度の経緯3段階、「決まった／まだ」4項目 | 最新状態と調査条件は短く常時表示。詳細は各論点の資料欄と後段の年表へ |
| 反応マップ | 予想2問、別の立場切替、7論点の山、選択中の論点、資料クイズ6問、海の下の論点、編集部の整理 | 立場切替を一本化。選択中の論点に関係する情報を集める |
| マップの下 | 8/24収集510件と9/17収集532件の比較 | 年表と近くに置く。制度の決定による変化と因果づけない |
| さらに下 | 資料照合6件の一覧、7論点×2件のX投稿 | 対応する論点の表示へ移す。クイズの答えも同じ資料を使う |
| 後半 | 実投票、授業用の理由3+3・資料3・問い3・印刷 | 投票を閲覧選択と区別。授業の理由から論点の表示へ戻れるようにする |
| 末尾 | 調査方法、関連テーマ、詳しい数値・検索語 | 保持。冒頭の案内と本文から到達できるようにする |

現行で冒頭の「条件付き」を押しても、マップの選択は「すべて」のままだった。
この操作はバーと立場の説明だけに効いており、マップ側の切替とは連動していない。
また、資料照合・クイズ・論点パネルで同じ資料が繰り返され、投稿例は別の長い一覧に離れている。

1280px幅で確認した際は、マップの開始が約3,000px、X投稿一覧が約8,650px、授業用が約13,700pxだった。
これは当日の画像・X埋め込みを含む表示例であり、端末共通の長さではない。問題は距離だけでなく、同じ論点を読むための行き来にある。

## どれとどれをつなぐか

論点IDで対応を取る。**立場で資料を選別せず、掲載した2つの投稿をそのまま資料照合の対象とみなさない。**

| 選ぶ論点 | 同じ場所に集める意見の内容 | 対応する制度・資料の内容 |
|---|---|---|
| 公約と政治不信（1,356件） | 実現までの遅さ／党内議論の報じ方の2投稿。理由の再読分類は未実施 | 7/30→8/5→9/15の経緯。「導入以来、税率が下がった例があるか」の照合1件 |
| 減税の対象範囲（885件） | 一律・廃止455件、時限・1%残しへの不満125件、食料品から実現94件など7分類。範囲が異なる2投稿 | 対象・税率・2年間という大綱の設計。「2年後は10%に戻る」の照合1件 |
| 減税の効果（717件） | 効果なし等295件、効果あり165件、限定的137件など5分類。遅さへの不満／減税の恩恵の2投稿 | 「価格に反映されなければ届かない」という共通の心配と、反映されるかについての異なる予測。資料照合の登録は0件 |
| 財源と社会保障（511件） | 社会保障削減／歳出の使い道の2投稿。理由の再読分類は未実施 | 大綱で決まった財源原則と未提示の内訳。年5兆円、社会保障への使途、輸出還付額の照合3件 |
| 給付など他策との比較（251件） | 給付69件、政府案への不満52件、減税43件など6分類。給付／減税の2投稿 | 減税と支援金を組み合わせる設計。収集した投稿では見つからなかった支援金の4条件 |
| 事業者の実務負担（112件） | レジ改修への反論38件、食品限定による負担24件など7分類。改修費支援／増税時との扱いの違いの2投稿 | 「1%とした理由はレジ改修」の照合1件。予約販売・簡易課税・総額表示の3措置。現場負担を認めたうえで補助か慎重判断かという違い |
| その他（58件） | 世論調査の聞き方／制度説明の分かりにくさの2投稿。理由の再読分類は未実施 | 調査方法への接続。対応する資料照合はなく、他の論点の資料を埋め草にしない |

投稿例は現行ページで編集部が選んだ2件を使う。左右の賛否を機械的に割り当てたり、比率を代表すると説明したりしない。
資料照合6件は各論点の `claims`、追加の4項目は `nearest_issue_id`、共通する心配2件は `issue_ids` で接続できる。
未登録の資料照合は「根拠がない」「間違い」という意味ではない。

## 配置と動作

1. **冒頭**: 中心の問い、画像、収集条件、最新の制度段階。長い年表を読む前に反応マップへ入れる。
2. **マップ**: 既存の予想2問、立場バー、共通の立場切替、山なみ、7論点の選択。
   Q1は立場の件数へ、Q2は強い表現の割合が最も高い山へつなぐ。回答は閲覧の必須条件にしない。
3. **選んだ論点**: PCでは「理由・投稿」と「制度・資料」を左右に配置、スマホでは上下に配置する。
   立場切替で山の件数を絞っても、理由の再読分類と投稿例は論点全体の内容であることを明記する。
   再読分類には立場別内訳がないため、選択した立場の理由だとは表示しない。
4. **資料**: 6問のクイズを別の長いブロックにせず、資料欄を問題表示に切り替える。
   問題を進めると対応する論点へ切り替わる。回答・結論・出典は同じ内容を使い、資料一覧に戻れる。
5. **経緯と収集比較**: 年表は3日付を選んで出来事を読む。過去の日付に現在の制度状態を付け替えない。
   収集比較は実在する2回分だけ。前後の投稿構成の差を、制度決定の影響や同じ人の転向とは説明しない。
6. **投票・授業・調査方法**: 投票は独立した2段階。表示案では外部へ送らず、選択内容の確認だけを行う。
   授業の理由から論点の理由と資料へつなぎ、公開ページの既存の印刷へ案内する。

山の切替は約0.5秒で補間し、端末の「動きを減らす」設定では即時表示にする。
論点ボタンで選ぶたびにページを大きくスクロールさせない。離れた制度・授業のリンクを明示的に押したときだけ対象へ移動する。
大きな既存図解は各論点から開ける。今回の会話内試作では図解画像そのものを作り直していない。

## 内容確認で見つかった別の修正候補

- 予想Q1の現行解説は、推進1,834件／反対・慎重1,035件に「差はわずか」と定型文を付けている。
  試作では評価語を外し「799件多い」にした。
- Q2の「強い表現がいちばん多い」は、実際には件数ではなく割合で判定している。
  試作では「割合が最も高い」にした（対象範囲464/885件、52.4%）。
- 末尾の調査説明に、条件付き109件・公約43.6%・その他6件など現在の集計と合わない数字が残っている。
  初期集計の説明として残すなら、その時期と母数を明示する必要がある。今回、本番本文は修正していない。
- 制度説明の確認日は9/19、資料照合6件の確認日は8/19。見せ方を変えても、同じ日に再確認したように表示しない。

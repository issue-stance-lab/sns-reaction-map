## 1. AI著作権：見解への肯定と利用への肯定

先に本人が評価する対象を決め、語調やハッシュタグだけで利用支持を補わない。

| 本人の主張（架空例） | 対象 | 検証用の正式ラベル候補 |
|---|---|---|
| 人間の創作的寄与で権利が生じるという見解は安心だ | 権利発生の見解 | 中立・情報 |
| この見解なら、企業は生成AIを積極的に使うべきだ | AI利用の推奨 | 推進・活用支持 |
| 生成AIは制作の選択肢として有益だ | AI利用自体の肯定 | 推進・活用支持 |
| 権利が生じるという見解には反対だ | 権利発生の見解 | 中立・情報。制限要求まで推測しない |
| 無断学習を禁止すべきだ | 学習制限の要求 | 規制・制限強化支持 |

「中立・情報」はこの既存ラベル上で利用推進・制限支持の表明がないという意味で、意見がないという意味ではない。本人の評価があればis_opinion=trueを保持する。利用への評価が省略され、発言者や対象も判別できない場合は中立へ埋めず文脈不足とする。両方向の要求が併存して主眼が決まらない場合も基準確認に残す。

再点検index 4は「AI生成物の権利・創作性／中立・情報／意見あり」を次回検証候補とする。v2の「この補足だけで既存採用を変更しない」は維持し、今回の具体化だけで現採用を書き換えない。

## 2. 副首都：地域の誘致反対は対象を別記する

検討記録に次を保存する。既存本番データへ新フィールドを直接追加しない。

- stance_target：本人が評価する対象の説明。
- target_scope：whole_policy（構想・法案全体）、local_bid（地域の誘致）、provision（個別条項）、other、unknown。
- target_stance：support、oppose、mixed、unexpressed、unknown。
- whole_policy_stance：全体への明示的賛否があれば既存ラベル、なければnull。
- aggregation_route：whole_policy、scoped_only、context_needed、criteria_needed。
- evidence：非公開根拠への参照、本文ハッシュ、基準バージョン、判断者と独立判断の記録。

| 架空例 | 対象への判断 | 全体への対応 |
|---|---|---|
| 福岡の誘致活動をやめてほしい | local_bid / oppose | null / scoped_only |
| 福岡への誘致には反対だが、副首都構想は進めるべきだ | local_bid / oppose | 法案賛成・推進 / whole_policy |
| 副首都を作る構想そのものを撤回すべきだ | whole_policy / oppose | 法案反対 / whole_policy |
| それはやめてほしい（対象不明） | unknown / unknown | null / context_needed |

再点検index 18は「費用・財源／意見あり、福岡の誘致活動／反対、全体賛否null、scoped_only」を検証候補とする。全体反対や中立に置き換えない。

将来の表示では「地域・条項への意見（全体賛否は未表明）」の別枠で件数と対象を示す。全体賛否の分布の分母にはwhole_policyだけを入れ、別枠件数と除外理由を併記する。投稿総数・論点別総数には含める。同じ投稿に全体への明示的賛否もあれば全体分布には1回だけ算入し、対象別注記を重複件数として加算しない。これは将来仕様であり、既存ページの分母変更は未実施。

## 次回の適用条件と処理順

1. 今回の2例を独立担当と照合し、仕様どおりに判断できることを確認する。過去の不一致・保留記録は保持する。
2. 既知の20例と重ならない20件（AI著作権10・副首都10、境界例と明示的賛否の対照例を含む）を固定し、2担当が個別に読む。候補一致数・不一致理由・対象範囲別件数を記録する。標本は境界検査用であり全体精度の推定に使わない。
3. 不一致は自動採用しない。同じ原因が残れば該当ルールだけを修正する。支持されたAI候補も既存の採用・隔離生成検査を経て別途登録する。
4. scoped_onlyは対象別記録・集計・表示・重複防止を実装し、その検査が通るまで現行採用台帳の保留を維持する。実装前のnullを本番分類へ渡さない。

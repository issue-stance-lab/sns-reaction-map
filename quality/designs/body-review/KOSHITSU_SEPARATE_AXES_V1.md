# 皇室典範の本文確認用・対象分離案 v1

2026-09-08、課題63。非公開の本文確認記録だけに使う検証案。
現行の「改正賛成・改正反対」と継承方針を対応付けない。本番分類器・採用台帳・公開集計は変更しない。

## 個別に保存する項目

本人の記述だけを根拠に、次を独立して判定する。

- `is_relevant`: 皇室制度・継承議論との関連性。
- `is_opinion`: 本人の評価・要求・論証があるか。ニュース見出し・動画紹介・第三者発言の共有だけは false。引用との境界が判別できなければ null。
- `main_issue`: 本文の主眼を短い自由記述で保存する。既存の論点ラベルへ無理に写像しない。
- `attribution`: author / third_party_only / mixed / unknown。本文に引用と本人の判断が両方あれば mixed。
- `reform_target`: current_package（本文で今回・この改正案等と特定）、specific_provision（特定措置）、alternative_reform（別の改正要求）、general_reform、unexpressed、unknown。
- `current_package_stance`: support / oppose / mixed / unexpressed / unknown。本文の今回改正案全体への本人の評価のみ。条項・別の改正案・継承方針から補わない。措置を分けて賛否を述べ、全体の結論がなければ mixed。
- `provisions`: 具体的措置への本人の判断を `{target, stance}` の配列で保持する。stance は support / oppose / mixed / unknown。
- `succession`: `male_line_only`, `female_sovereign`, `female_line`, `named_successor_aiko` の4項目に support / oppose / mixed / unexpressed / unknown を保存する。「女性天皇」支持から「女系天皇」支持は推測しない。男系限定支持だけで女性天皇反対としない。「愛子天皇」本人支持は女性天皇支持も含意するが、女系容認は補わない。
- `other_succession`: 上の4項目では表せない方針は短い記述。皇統の断絶・制度廃止等を男系・女系の賛否へ変換しない。
- `uncertain`, `evidence_sufficient`, `reason`: 不確実性、上記の読解に本文が十分か、短い個別理由。事実の正しさを認定した意味ではない。
- `aggregation_route`: 常に criteria_needed。既存の立場ラベル候補は null のままにして保留する。

`unexpressed` は本人によるその対象への表明がない、`unknown` は対象や発言帰属の不足で判定できない意味。本人の論証に明確な方向があれば、それを保存してよいが主張されていない制度の賛否を足さない。

## 境界

「現在案は反対、女性天皇を認める案へ変えるべき」は現在案反対・女性天皇支持。「旧宮家養子は必要、結婚後の女性皇族の皇籍保持は不要」は措置別に分け、現在案全体の断定はしない。「愛子さま即位へ改正」は別案支持であり現在案賛成へ移さない。「女性天皇とは何か」という説明や問いだけから賛否を補わない。記事・動画題名の賛否は本人の値へ移さない。

## 検証と適用境界

既存確認済みの単一テーマ最大20件を固定し、現行分類・過去編集値・相手の新判断を除いた同じ packet で2担当が先に保存してから比較する。代表例検査は新規本文確認へ加算しない。

相違は元回答を残して保留する。合意した追加項目も公開の賛否集計へは入れない。現在の一軸ラベルを埋めるためだけにこの案を使わない。新規本文確認で皇室テーマを進める条件は、代表例の独立検証が終わり、同じ2軸を各投稿に保存できる状態になること。既存分類の置換は別工程。

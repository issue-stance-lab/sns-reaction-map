### 資料B

## 3. ルールの曖昧さ

### 資料F
- 発行機関 / 警察庁 / よくある質問｜自転車ポータルサイト / URL: https://www.npa.go.jp/bureau/traffic/bicycle/portal/faq.html / 該当箇所: Q.自転車は車道通行が原則と言われていますが、いかなる場合も車道を通行しなければならないのですか。 / Q.子どもでも歩道は通行できないのですか。
- 確かめられる事実: 歩道は歩行者のために整備されているため自転車は原則として車道を通行するが、13歳未満の子どもは歩道を通行できる。また、歩道の中央から車道寄りの部分を徐行（直ちに停止できるような速度で進行）する必要がある。運転者が車道を通行することが危険であるような車道又は交通の具体的な状況を認識した場合には歩道を通行することができる。
- 確認日: 2026-08-30

### 資料G
- 発行機関 / 警察庁 / よくある質問｜自転車ポータルサイト / URL: https://www.npa.go.jp/bureau/traffic/bicycle/portal/faq.html / 該当箇所: Q.イヤホンをしながら運転したら、取締りを受けるのですか。 / Q.傘の固定器具を自転車のハンドルにつけて傘差し運転したら、取締りを受けるのですか。 / Q.ハンドルに荷物を掛けて運転したら、取締りを受けるのですか。
- 確かめられる事実: イヤホンをしながら運転すること自体が直ちに違反になるわけではないが、安全な運転に必要な交通に関する音又は声が聞こえないと認められる状態で運転することは禁止されている。ただし、この違反をしていることだけで取締りを受けることはなく、違反の結果実際に交通への危険を生じさせたり事故の危険が高まっていたりした場合などに取締りを受ける可能性がある。傘差し運転も同様に、固定器具を用いて運転者の視野やハンドル操作を妨げる場合や、公安委員会が定める積載制限を超える大きさの傘を固定する場合は違反となる可能性があるが、違反であることを認識しながらあえて行い、かつ危険が生じた場合などに取締り対象となる。
- 確認日: 2026-08-30

### 資料H
- 発行機関 / 警察庁 / よくある質問｜自転車ポータルサイト / URL: https://www.npa.go.jp/bureau/traffic/bicycle/portal/faq.html / 該当箇所: Q.ながら運転について、自転車に取り付けてある携帯電話・スマートフォンを確認する場合も取締りを受けるのですか。
- 確かめられる事実: 自転車に取り付けてあっても携帯電話・スマートフォンを注視することは道路交通法により禁止されている。これに違反して実際に交通の危険を生じさせた場合は赤切符（刑事手続）の対象となる。交通の危険を生じさせていない場合は取締りを受けることはない。
- 確認日: 2026-08-30

### 資料I
- 発行機関 / 警察庁 / よくある質問｜自転車ポータルサイト / URL: https://www.npa.go.jp/bureau/traffic/bicycle/portal/faq.html / 該当箇所: Q.令和8年4月1日から施行された「側方通過」の規定とは何ですか。
- 確かめられる事実: 道路交通法が改正され、自動車が自転車を追い抜く際に、十分な間隔を保ち、安全な速度で追い抜かなければならない規定が令和8年4月1日から施行された。警察庁は「十分な間隔」や「安全な速度」の目安として、自転車の平均速度が時速10キロメートルから時速20キロメートル程度であることを踏まえ、十分な間隔がとれない場合には自動車は一定程度減速した上で当該自転車を追い抜くことを想定したものと示している。
- 確認日: 2026-08-30

## 4. 免許制

### 資料K
- 発行機関 / 警察庁 / よくある質問｜自転車ポータルサイト / URL: https://www.npa.go.jp/bureau/traffic/bicycle/portal/faq.html / 該当箇所: Q.運転免許証を持っていませんが、取締りを受けたときはどのように本人確認を行うのですか。 / Q.自転車の違反で取締りを受けた場合、運転免許証にも影響があるのですか。
- 確かめられる事実: 運転免許証を持っていない場合にはマイナンバーカードや学生証といった他の身分証で本人確認を行う。身分証を持っていない場合は自己申告に加え家族に連絡をするなどして確認する。運転免許を有している者が自転車で交通違反を犯した場合であっても、運転免許の点数が付されることはない。ただし、自転車でひき逃げ事件や死亡事故等の重大な交通事故を起こした場合や飲酒運転など特に悪質・危険な違反を犯した場合など、各都道府県公安委員会が自動車等を運転することが著しく道路における交通の危険を生じさせるおそれがあると認めるときは、運転免許の停止処分が行われることがある。
- 確認日: 2026-08-30

> **徐行しなければならず**、また、普通自転車の進行が歩行者の通行を妨げることとなるときは、**一時停止しなければならない**。

### 結論：自転車の方向指示器・制動灯の基準を定めた規定は、見つからなかった

**2026-10-16に @aoi_tyarinko へ返した文（下り坂で減速するときの合図）の弱点が、ここで埋まった。**
根拠は3段で、どの段にも自転車の方向指示器・制動灯は出てこない。

| 段 | 条文 | 中身 |
|---|---|---|
| 1 | 道路運送車両法施行令 第1条 | **軽車両の列挙に、ふつうの二輪自転車が入っていない** |
| 2 | 道路運送車両法 第45条 | 軽車両に求める保安基準は5項目だけで、**制動灯も方向指示器も無い**（原付の第44条には両方ある） |
| 3 | 道路運送車両の保安基準 第四章 | 軽車両の章は6条だけで、**灯火の条が1つもない** |

したがって、**施行令第21条の表が徐行・停止の合図として挙げる「車両の保安基準に関する規定により設けられる制動灯」は、自転車には存在しえない選択肢**であり、
**自転車の徐行・停止の合図は、事実上「腕を車体の外に出して斜め下に伸ばす」の一択になる。**

### 資料W-7b（自転車の灯火は、国ではなく都道府県が決めている）【2026-10-18確認】
- **道路交通法施行令 第18条第1項**: 自動車・原付の灯火は「保安基準に関する規定により設けられる」ものと書くのに対し、
  **第5号の「軽車両」は「公安委員会が定める灯火」**としている。
- 調べた3県の規則は、いずれも**前照灯・尾灯・反射器材だけ**を定め、**「方向指示器」「制動灯」は規則全文で0件**。

| 県 | 条 | 尾灯の色 |
|---|---|---|
| 東京都道路交通規則 | 第9条 | **赤色** |
| 大阪府道路交通規則 | 第10条 | **橙色又は赤色** |

- **読み取れること**: **自転車の灯火の基準は県ごとに違う。**全国一律ではない。

### 資料W-9b（警察庁の概要資料：取締りの考え方は青切符の前後で変えない）【2026-10-18確認】
- URL（本文PDF）: https://www.npa.go.jp/bureau/traffic/bicycle/pdf/gaiyousiryou.pdf
- 原文:
  - 「自転車の指導取締りの基本的な考え方 → **青切符の導入前後で変わらず**」
  - 「○ 自転車の交通違反を認知した場合、**基本的には現場で指導警告を実施**」
  - 「○ ただし、その違反が交通事故の原因となるような、歩行者や他の車両にとって、危険性・迷惑性が高い
    悪質・危険な違反…であるときは検挙の対象」
  - **指導警告にとどまる例**:「・**スピードを出して歩道を通行**」「・16歳未満の者による違反」
  - **青切符になる例**:「・スマホを持って画面を注視したり、通話をする」「・信号無視で交差点に進入し、
    他の車両に急ブレーキをかけさせる」「傘を差しながら一時不停止をしたとき」
    「警察官による指導警告に従わず、右側通行を継続したとき」
  - **刑事手続に回る例**:「・酒酔い運転・酒気帯び運転」「・違反により実際に交通事故を発生させる」
- **読み取れること（投稿に使える非対称）**: **「スピードを出して歩道を通行」は、条文上は反則金3,000円の対象だが、
  警察庁の例示では「指導警告」の側に置かれている。**条文上の対象と運用の二層構造。
  警察庁自身が「青切符で変わるのは検挙後の手続」と書いており、**報道の「取締り強化」という枠組みとはニュアンスが違う。**

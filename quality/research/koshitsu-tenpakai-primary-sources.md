## 2. 旧宮家養子縁組

### 資料A
- 発行機関 / 文書名 / 発行日 / URL / 該当箇所
  - 国立国会図書館 / 第221回国会 参議院 皇室典範等の一部を改正する法律案特別委員会 第3号 / 令和8年7月16日 / https://kokkai.ndl.go.jp/#/detail?minId=122115389X00320260716 / 発言番号002（長浜博行）
- 確かめられる事実: 旧十一宮家から養子を受け入れ、その子孫が皇位継承の資格を有するものとすることについては、立法府の総意として「合意されていない」と長浜博行が指摘。政府提出法案には養子に関する改正規定が含まれていたが、立憲民主・無所属提出の修正案では「皇族の養子に関する事項に係る改正規定を削る」こととした。現行皇室典範第九条では「天皇及び皇族は、養子をすることができない」と規定。
- 確認日: 2026-08-30

## 4. 女性天皇・女系天皇

### 資料A
- 発行機関 / 文書名 / 発行日 / URL / 該当箇所
  - e-Gov法令検索 / 皇室典範（昭和二十二年法律第三号） / 令和8年7月24日施行版 / https://laws.e-gov.go.jp/law/322AC0000000003 / 第一条
- 確かめられる事実: 皇位は、皇統に属する男系の男子が継承する（第一条）。女系天皇（母方から天皇の血統を引く女性またはその子孫が天皇になること）は、現行皇室典範では明文で排除されている。皇室典範の条文上「女性天皇」は禁止されていないが、皇位継承資格は「男系の男子」に限定されるため、女系天皇は不可能。
- 確認日: 2026-08-30

### 資料B
- 発行機関 / 文書名 / 発行日 / URL / 該当箇所
  - 国立国会図書館 / 第221回国会 参議院 皇室典範等の一部を改正する法律案特別委員会 第3号 / 令和8年7月16日 / https://kokkai.ndl.go.jp/#/detail?minId=122115389X00320260716 / 発言番号002
- 確かめられる事実: 長浜博行は「皇紀二千六百八十六年、百二十六代、天皇は男に決まっている、ほぼそうだった、これが伝統であり」との意見に対し、「かつて日本では、男性しか国の象徴になれなかった時代があった」と反論。女系天皇の容認を示唆する発言があるが、これは議員の個人的見解。
- 確認日: 2026-08-30

## 5. 皇族の身分と地位

### 資料A
- 発行機関 / 文書名 / 発行日 / URL / 該当箇所
  - e-Gov法令検索 / 皇室典範（昭和二十二年法律第三号） / 令和8年7月24日施行版 / https://laws.e-gov.go.jp/law/322AC0000000003 / 第五条〜第十五条
- 確かめられる事実: 皇族の範囲は、皇后、太皇太后、皇太后、親王、親王妃、内親王、王、王妃及び女王（第五条）。嫡出の皇子及び嫡男系嫡出の皇孫は、男を親王、女を内親王とし、三世以下は男を王、女を女王とする（第六条）。皇族女子は、天皇及び皇族以外の者と婚姻したときは皇族の身分を離れる（第十二条）。内親王、王及び女王は、意思に基づき皇室会議の議により皇族の身分を離れる（第十一条）。皇族以外の者が皇族となるのは、女子が皇后となる場合及び皇族男子と婚姻する場合のみ（第十五条）。
- 確認日: 2026-08-30

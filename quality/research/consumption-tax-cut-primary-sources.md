## 4. 財源と社会保障

- 確かめられる事実: 食料品ゼロ税率の財源として「積み過ぎ基金」「外為特会剰余金」「租税特別措置の見直し」を挙げ、兆単位での確保を主張。給付付き税額控除の財源は「金融所得課税改革」等で確保する方針。ただしこれは政党の財源案であり、政府の財源計画ではない。
- 確認日: 2026-08-30

**※消費税減税が社会保障財源に与える影響を定量的に示す政府資料（財務省試算等）は確認できず。**

## 6. 事業者の実務負担

### 資料K
- 発行機関 / 文書名 / 発行日 / URL / 該当箇所
  - 国税庁 / 「軽減税率制度の概要」 / 掲載中 / https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/keigenzeiritsu.htm / 適格請求書等保存方式（インボイス制度）項
- 確かめられる事実: 軽減税率制度実施に伴い、事業者は「区分経理」（税率ごとに取引を区分して記帳）が必要。インボイス制度では、課税仕入れ等に係る消費税額を控除するために、区分経理に対応した帳簿及び適格請求書（インボイス）等の保存が必要。
- 確認日: 2026-08-30

### 資料L
- 発行機関 / 文書名 / 発行日 / URL / 該当箇所

- 確かめられる事実: 「飲食料品の取扱い（販売）がない事業者の方についても、消費税の軽減税率制度実施後は『区分経理』が必要となります」と明記。軽減税率対象外の事業者でも経理負担が生じることを国税庁が公表している。

## 確認できなかったこと

1. **減税の効果に関する政府試算**
   - 財務省・国税庁が公表した「消費税減税による物価・購買力・GDPへの影響試算」は一次資料として確認できなかった。政党公約の数字（5兆円等）は政党独自試算に過ぎない。

2. **公約と政治不信の因果関係を示す統計**
   - 内閣府「社会意識に関する世論調査」や総務省統計局の家計調査等で、消費税公約と政治不信の相関を直接示す一次資料は確認できなかった。世論調査の時系列データが必要だが、該当する設問を確認できなかった。

3. **財源と社会保障の影響評価**
   - 消費税収が社会保障財源（約11.3兆円、令和5年度）のうち約36%を占める（財務省「税の構成」等）が、減税が年金・医療・介護給付に与える具体的影響を定量化した政府資料は確認できなかった。

4. **給付と減税の比較に関する政府資料**
   - 同規模の財源で「一律給付」「給付付き税額控除」「税率減免」のどれが所得再分配効果・景気刺激効果で優位か、を定量的に比較した内閣府・財務省の公表資料は確認できなかった。

5. **事業者の実務負担に関する数値調査**
   - 軽減税率制度・インボイス制度導入による事業者の「経理コスト増大額」「人手増加数」等を数値化した独立行政法人・税務署等の調査報告書は確認できなかった。中小企業庁の実態調査等が存在する可能性があるが、該当一次資料に到達できなかった。

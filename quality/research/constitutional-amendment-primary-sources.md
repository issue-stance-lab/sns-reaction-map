## 2. 9条と自衛隊

### 資料D-2（衆議院憲法調査会の議論・両論併記）
- 発行機関 / 衆議院憲法審査会事務局 / 「衆議院憲法審査会 関係資料集」令和8年版 / URL: https://www.shugiin.go.jp/internet/itdb_kenpou.nsf/html/kenpou/r8_shiryosyu.pdf/$File/r8_shiryosyu.pdf / 該当箇所: Ⅳ「衆議院憲法調査会における議論」安全保障・国際協力（報告書301〜302頁の要約、原本は衆議院憲法調査会報告書）
- 確かめられる事実: 過去の衆議院憲法調査会での議論を、事務局が両論併記でまとめている。
  - **9条への評価**（多数意見）: 「戦後の日本の平和と安定・発展に大きく寄与してきた」「単なる理念ではなく、軍事大国に進まない歯止めとなっている」「アジア各国からの平和主義への支持と積極的な評価からも明らか」等、少なくとも1項の戦争放棄の理念は堅持すべきとの意見が多く述べられた
  - これに対し、「9条があることで日本が紛争を起こさず侵略もされていない」という説明に対し、「日米安全保障条約及び自衛隊の存在があったからこそ平和と経済的繁栄を享受してきた」という反論意見も記録
  - **自衛権及び自衛隊**: 「自衛権の行使としてであっても武力の行使は認められない」とする意見もあったが、「自衛権の行使として必要最小限度の武力の行使を認める」意見が多く述べられた
  - 出典は衆議院憲法調査会の報告書（301〜302頁）で、この資料集はその要約。
  - 【2026-08-31追記・原本で一字一句確認】オーナー提示の一覧ページ（https://www.shugiin.go.jp/internet/itdb_kenpou.nsf/html/kenpou/shiryo.htm ）から「憲法調査会報告書」（平成17年4月15日、中山太郎会長→河野洋平衆議院議長提出、URL: https://www.shugiin.go.jp/internet/itdb_kenpou.nsf/html/kenpou/houkoku.pdf/$File/houkoku.pdf ）原本を取得。上記②の「9条は単なる理念ではなく、軍事大国に進まない歯止めとなっている」の一文が、原本の当該箇所と一字一句一致することを確認した。
- 確認日: 2026-08-31

## 3. 緊急事態条項

### 資料E
- 発行機関: 国立国会図書館（国会会議録検索システム）
- 文書名: 衆議院憲法審査会議事録 第13号

- URL: https://kokkai.ndl.go.jp/#/detail?minId=122104183X01320260716
- 該当箇所: 新藤義孝発言（speechOrder 2）
- 確かめられる事実: 緊急事態条項の対象範囲として「大規模自然災害、感染症の蔓延、テロ・内乱、外部からの武力攻撃」の四つを定義。選挙困難事態の認定、議員任期延長、解散で身分を失った議員の身分復活を図る。究極の緊急事態に備え、内閣が緊急政令を制定し緊急財政処分を行える制度を提案。憲法制定時に日本政府がGHQに対し緊急事態条項を提案したが拒否された歴史に言及。
- 確認日: 2026-08-30

### 資料E-2（衆議院憲法調査会の議論・両論併記）
- 発行機関 / 衆議院憲法審査会事務局 / 「衆議院憲法審査会 関係資料集」令和8年版 / URL: https://www.shugiin.go.jp/internet/itdb_kenpou.nsf/html/kenpou/r8_shiryosyu.pdf/$File/r8_shiryosyu.pdf / 該当箇所: Ⅳ「衆議院憲法調査会における議論」非常事態（報告書463頁〜の要約）
- 確かめられる事実: 現行憲法に非常事態規定が無いことへの評価を巡り、規定すべきとの意見が多く述べられたと整理されている。
  - **規定すべき理由**（多く述べられた）: ①非常事態では首相への権限集中・一元的処理と人権の平常時以上の制約が必要になる場合があり、その要件・手続・効果は憲法事項であること、②地域紛争・環境劣化・グローバリズム・テロ等、現代社会は多様な危険を内包しているのに対処規定が無いのは「憲法の欠陥」であること、③非常事態対処は為政者の超法規的措置を誘発しやすく、それを防ぐための憲法保障として規定が必要であること
  - **規定すべきでないとする意見**: 現行憲法が明文規定を持たないことの意義（非常事態を生じさせないよう努力すべきことが規範としてある）を指摘
  - 資料Eの新藤義孝発言（2026年、自民党の具体的な条項案）と、この過去の憲法調査会での賛否両論の整理を合わせて読むと、「規定すべき」という大枠の方向性は長年の議論の蓄積があり、現在の自民党案はその延長線上にあると分かる。
  - 【2026-08-31追記・原本で一字一句確認】憲法調査会報告書原本（平成17年4月15日、URL: https://www.shugiin.go.jp/internet/itdb_kenpou.nsf/html/kenpou/houkoku.pdf/$File/houkoku.pdf ）で、③の「非常事態への対処に当たっては、為政者に超法規的措置の発動を誘発することが多いので、憲法保障の観点から」の一文が原本と一字一句一致することを確認した。
- 確認日: 2026-08-31

### 資料E-3（参議院版の緊急事態論議・政党の論点整理を引用）
- 発行機関 / 参議院憲法調査会 / 「日本国憲法に関する調査報告書」 / 平成17年4月20日 / URL: https://www.sangiin.go.jp/japanese/kenpou/houkokusyo/pdf/honhoukoku.pdf / 該当箇所: 「７ 緊急・非常事態法制」（p.99前後）
- 確かめられる事実: 参議院版は、衆議院版とは異なる切り口・異なる引用で同じ論点を整理している。
  - 規定を置くことに積極的な意見の1つとして、自由民主党「党の論点整理」（平成16年）を名指しで引用: 「非常事態全般、すなわち有事、テロ、大規模な暴動などの治安的緊急事態、自然災害の場合に関する規定を置くべきとの意見が出た」
  - 「憲法制定時は占領下で緊急事態を想定する必要がなかったこと、ドイツでは戦後十数年たって緊急事態の規定を設ける憲法改正を行ったこと等にかんがみれば、憲法上、緊急権や緊急事態に関する規定がないのは、**憲法の欠缺**である」という、衆議院版とほぼ同旨だが独自の言い回し（「欠缺」）による意見も記録
  - 消極的な意見として「緊急事態法制がないという憲法の沈黙は、法の欠陥ではなく、平和主義と積極的にリンクしていくとの意見は示唆に富むもの」という、衆議院版には無い角度の反論を記録
  - 「緊急・非常事態に関する規定を憲法に置くことは基本的人権との関係で難しいため、憲法は現状のままとして、緊急・非常事態に対処する基本法を制定し」という第三の立場（憲法改正ではなく法律で対応）も記録している。衆参どちらも「規定すべき」「すべきでない」の二項対立に見えがちだが、実際には「法律で対応」という中間的立場も議論されていたことが分かる。
- 確認日: 2026-08-31

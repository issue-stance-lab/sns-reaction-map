# loop-dispatch — 自律ループ用の発注・起動スクリプト（2026-06、未成立）

「ハブAIが課題を選び、ワーカーAIへ自動で割り振って起動する」自律ループを目指して作った3本。
**完全なループにはならず、運用に乗らないまま止まった。**

| ファイル | 役割 |
|---|---|
| `assign_task.py` | 課題番号とAI名から発注書を生成し、クリップボードへコピー |
| `run_ai_agent.py` | ワーカーAIを起動して発注書を渡す |
| `run_hermes_agent.py` | Hermes 専用の起動ラッパー |

## なぜ運用に乗らなかったか（2026-08-07 の棚卸しで確認した事実）

- **課題番号の前提が食い違っていた。** `--issue 8` のように GitHub Issue 番号を前提にした
  作りだが、このプロジェクトは課題を `TASK_BOARD.md` で管理していて Issue を使っていない
- **分業そのものが縮小した。** 発注先は 2026-06 に4体制（Antigravity/Hermes/Codex/Claude Code）
  → 2026-07 に2体制 → 2026-08 は Codex のみ17本。割り振る相手がいなくなった
- **定期実行の登録がない。** cron / launchd いずれにも登録されておらず、自動では起動しない
- 3本は互いにしか参照し合っておらず、他のどこからも呼ばれていない

## 現在の実態

発注書は人が `configs/prompts/codex/` へ置き、オーナーが Codex に渡している。
手順は `LOOP.md` ③ を参照。

- `verify_top_page.py` に「置換の空振り」「正典ファイル」「日付」「禁止表示」「リンク」の検査あり。負のテストで動作確認済み

---

### 背景（調査済みの事実。再調査不要）

**S2 で追加した要素が、モバイルで完全に消える状態になっている。**

現在の CSS：

```css
@media(max-width:1050px){ .hero-side{display:none} }
```

そして S2 で追加した2つのパネルは、両方とも `.hero-side` の中にある。

```html
<aside class="hero-side">
  <a class="mini-panel mini-panel-link" ...>いま考えたい問い / AI学習が合法なら…</a>
  <div class="mini-panel reading-guide">このサイトの読み方 / 掲載内容は…世論調査ではありません</div>
</aside>
```

つまり **1050px 未満では、注目の問いも「世論調査ではありません」という注意書きも一切表示されない。**

これは元々ドーナツと推移グラフ（見えなくても実害のない装飾）が入っていた枠を流用したために起きている。**中身の性質が変わったのに、非表示ルールがそのまま残っている。**

特に注意書きの消失は、S1〜S2 で回復させた信頼性を、閲覧者の大半を占めるモバイルで無効化する。**このタスクの最優先項目。**

---

### 目的

トップページの改修を、PC だけでなくモバイルでも成立させる。
特に「注意書きが常に見える」ことを保証する。

---

### やること

#### Step 1: `.hero-side{display:none}` を廃止し、縦積みに変更する

`@media(max-width:1050px)` の `.hero-side{display:none}` を削除し、レイアウトを組み直す。

**PC（1051px 以上）** — 現在の3列を維持

| 左 | 中央 | 右 |
|---|---|---|
| コピー・CTA | 論点整理のイメージ | いま考えたい問い ＋ このサイトの読み方 |

**タブレット・スマホ（1050px 以下）** — 縦積み

1. コピー・CTA
2. 論点整理のイメージ
3. いま考えたい問い
4. このサイトの読み方（**注意書きを含む。絶対に非表示にしない**）
5. ヒーロー統計
6. 注目の4つの問い
7. テーマ一覧

390px 幅でカードが窮屈になる場合は、パネルの padding とフォントサイズを調整する。**`display:none` で逃げないこと。**

#### Step 2: ヒーロー統計の3枠目を「調査方法」に変える

現在の3枠：

```
分類済み投稿 4,495 / 7/29更新
公開中のテーマ 11 / 11テーマで投票受付中
次回データ更新 8/2 / あと7日
```

3枠目は数字ではあるが、閲覧者にとっての価値が低い。**「次回データ更新」は update-bar に既に同じ情報がある**ため、ヒーロー統計からは外し、代わりに調査方法への導線を置く。

```
分類済み投稿 4,495 / 7/29更新
公開中のテーマ 11 / 11テーマで投票受付中
調査方法を公開 / 検索条件・AI分類・注意点を見る → about.html
```

**注意**: `hero-next-update` / `hero-days-left` の id を削除する場合、`sync_portal_stats.py` の該当置換と `verify_top_page.py` の空振り検査も同時に更新すること。**置換対象が消えたのに検査だけ残ると、次回実行時に「0件マッチ」で異常終了する。** update-bar 側の次回更新表示は残すので、そちらの置換は維持する。

#### Step 3: 注意書きの配置を確認する

`archive/planning-2026-08/WORK_PLAN_2026-08.md` A-4 の方針に従い、注意書きは**最初の数字の直前かそれより上**に置く。

現在「このサイトの読み方」パネル内にあるが、モバイルの縦積みでヒーロー統計より下に来る場合は、**注意書きだけをヒーロー統計の直前に出す**などして順序を守る。

#### Step 4: verify_top_page.py に検査を追加する

```
=== レスポンシブ ===
OK  .hero-side に display:none を適用するメディアクエリなし
OK  「世論調査ではありません」がページ内に存在する
OK  注意書きが hero-stats より前に出現する
```

**S1・S2 と同様、意図的に壊して NG と exit 1 を確認すること。**

#### Step 5: 実機幅で目視確認する

- **1280px**: 3列が維持され、不自然な空白がない
- **768px**: 縦積みに切り替わり、全パネルが見える
- **390px**: 横スクロールなし、文字がカード外にはみ出さない、問いカード4枚すべて表示

### 制約（必ず守る）

- 保護タグを壊さない: GA4 `G-K10S4YCZFH` / AdSense `ca-pub-2542211932832864` / Supabase / OGP
- ブランチ: `task/homepage-responsive`。main 直接コミット禁止
- `docs/index.html` を `build_site_portal.py` で生成しない
- 数値をハードコードしない
- **`display:none` でモバイルの要素を消して解決しない。** 消していいのは装飾のみで、情報・注意書き・導線は消さない
- ナビリンクを変更する場合は、参照している他ページ（`usage.html` / `topic-modern.js` / 各テーマHTML）も同時に更新する

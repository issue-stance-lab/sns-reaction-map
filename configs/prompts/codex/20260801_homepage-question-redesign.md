`WORK_PLAN_2026-08.md` §3 A-1

- `sync_portal_stats.py` は実ファイルのレコード数から件数を計算する（4,495件）

- 「置換の空振り検査」「正典ファイル検査」「日付検査」は実装済み
- **「禁止表示」「リンク」セクションは枠だけの空の状態 → このタスクで中身を入れる**

---

### 目的

トップページから、どのデータからも計算されていない数字を消す。
同時に、消した跡が空白にならないよう「問い」に差し替える。

**削除と追加は必ず同一PRで行う。** 削除だけ先に出すとトップがスカスカになる。

---

### やること

#### Step 1: 削除する

`docs/index.html` から以下を除去する。

| 対象 | 現在の値 | 問題 |
|---|---|---|
| 公開テーマの分類比率ドーナツ | 38/33/17/12% | 由来なし。どのデータからも計算されていない |
| 最近の分類件数グラフ | 7/7〜7/12 の固定棒 | 8月になっても7月の日付。棒の高さも固定値 |
| 割れ度ランキング（4カード） | 78/76/74/72 | 算出ロジックが存在しない |
| ランキング内の各テーマ割合 | 29/26/35/10% 等 | 手入力 |
| ナビの「ランキング」項目 | — | 遷移先がなくなるため |
| `#ranking` アンカー | — | 他ページからの参照も確認して除去 |

関連する CSS（`.donut` `.trend` `.split-score` `.rank-*` 等）で未使用になるものも削除する。

#### Step 2: 差し替えて追加する

| 空いた位置 | 入れるもの |
|---|---|
| ドーナツ枠 | 「いま考えたい問い」（1件、テキスト＋テーマへのリンク） |
| 推移グラフ枠 | 「このサイトの読み方」（3〜4行＋ `about.html` へのリンク） |
| 割れ度4カード | 「いま考えたい4つの問い」（下記4件） |
| 中央マップ | 「論点整理のイメージ」ラベルを明示（実データの可視化ではないことを示す） |
| ナビ | 「ランキング」→「注目の問い」 |

**掲載する4つの問い**

| # | 問い | リンク先テーマ |
|---|---|---|
| 1 | AI学習が合法なら、創作者への対価は不要なのか？ | `ai-copyright` |
| 2 | 自転車の取り締まりと道路整備、どちらが先か？ | `bike-blue-ticket` |
| 3 | 教員の負担を減らして、家庭の負担が増えてもよいか？ | `bukatsu-chiiki` |
| 4 | 減税で浮いた分を、10年後の自分の年金から出してもよいか？ | `consumption-tax-cut` |

各カードには問いに加えて、テーマ名と `sample_file` 由来の件数（例: 分類済み 708件）を添える。**割合・順位・スコアは載せない。**

「このサイトの読み方」の文面は以下を骨子とする。

```
1. 問いを選ぶ
2. 賛成・反対それぞれの理由を読む
3. 自分と遠い意見も1つ読む
4. 一次情報を確認する

掲載内容はSNS公開投稿のサンプルを整理したものであり、
社会全体の世論調査ではありません。
```

#### Step 3: 選定基準を GROWTH.yaml に記録する

なぜこの4テーマ・この4問なのかを `GROWTH.yaml` に記録する。基準のない選抜は、割れ度ランキングと同じ「説明できない表示」に将来なる。

```yaml
featured_questions:
  updated_at: 2026-08-01
  criteria: |
    - 賛否が価値観の対立に還元できる（事実確認だけで決着しない）
    - 読者自身がコストを負担する立場になりうる
    - 分類済み件数が300件以上
  items:
    - theme: ai-copyright
      question: AI学習が合法なら、創作者への対価は不要なのか？
```

#### Step 4: verify_top_page.py に検査ルールを追加する

空だった2セクションを埋める。**S1と同じ品質で、実際に検出できることを負のテストで確認すること。**

```
=== 禁止表示 ===
OK  「割れ度」なし
OK  「公開テーマの分類比率」なし
OK  「どっちが多い」なし
OK  30日以上前の日付を含む要素なし
OK  ハードコードされた割合（NN%）なし

=== リンク ===
OK  問いカード 4/4 リンク有効（リンク先HTMLが実在する）
OK  #ranking 参照なし
OK  ナビの全リンク先が実在する
```

- NG が1件でもあれば exit 1
- 空セクションが残る場合は `（未設定）` と明示する（OKと誤読させない）

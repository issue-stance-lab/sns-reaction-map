## 何をするか

11テーマのページは「テーマ / 論点 / 賛否 / Xの表示（散布マップ）」で構成されている。
このうち**何件を数えているかがテーマごとに違い**、比較も検証もできない状態だった。

| 現状 | テーマ |
|---|---|
| 意見のみを数えている（正しい形） | 消費税・部活動・生成AI・高市・あだ名・副首都・自転車 |
| 論点と賛否は意見のみ、**マップだけ全件** | 皇室典範・高齢者免許 |
| ページが正典の**一部だけ**を使っている | 憲法改正・辺野古 |

オーナー判断で、**全テーマ「意見のみを数える」に統一する**ことに決まった。

決めたルールは3行。

1. 数えるのは「意見」だけ。収集件数と意見件数の両方をページに出す
2. 論点・賛否・マップの点は、同じ意見の集合を数える。3つの合計は必ず一致する
3. 賛否は4つ（賛成 / 反対 / 条件付き / 中立）。賛否で切れないテーマは賛否を出さない

**この一連の作業が扱うのは 1 と 2。3 は別途。**

## 全セッション共通の歯止め

各ファイルにも書いてあるが、特に重要なもの。

- **賛否の選択肢と論点カードの枚数を変えない。** 数が変わると読者投票の `choiceIdx` の
  意味がずれ、Supabase Edge Function の再デプロイが必要になる（皇室典範で実際に発生）。
  **今回変わるのは件数だけ**
- **件数が減るのは正常。** ニュース共有が外れるためで、劣化ではない
- **点が減って見栄えが悪くなっても、勝手に点を戻さない。** そのまま報告する

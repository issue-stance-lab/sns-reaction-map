# 第3回「お金と送迎編」｜費用・負担の一次資料リサーチ

調査日: 2026-08-25
対象: 部活動の地域移行（地域展開）における費用・保護者負担・指導者報酬
用途: note第3回の裏付け。ここに載っていない数字は記事に書かない

---

## 0. いちばん重要な発見

**実証段階は参加費0円の自治体が多かった。本格実施で有料になった。**

そして本格実施の補助は **国1/3・都道府県1/3・市区町村1/3**。
自治体が1/3を出せなければ、残りは家庭へ回る。

これが「同じ制度なのに自治体で会費がまるで違う」ことの構造的な理由になる。

## 3. 本格実施の実例（神栖市・令和6年9月〜）

出典: [かみす地域クラブに関するQ&A（神栖市教育委員会）](https://www.city.kamisu.ibaraki.jp/_res/projects/default_project/_page_/001/011/583/26qa.pdf)

| 項目 | 金額・条件 |
|---|---|
| 会費 | **年会費1,000円、月会費2,000円** |
| 指導者報酬 | **1時間当たり1,700円**（原則1回3時間の指導） |
| 指導者の交通費 | 1回の活動につき1,000円 |
| サポーター | 1時間当たり1,000円（交通費の支給なし） |
| 体制 | 「１団体２人で指導することを基本」 |
| 送迎 | 「活動の拠点校となる会場への移動は、自転車や保護者による送迎をお願い」 |
| 場所 | 「直営型クラブは主に学校の施設を借用して実施」 |

**注意**: 会費収入と指導者報酬の差額を、いくらの公費で埋めているかは公表資料から確認できなかった。
**「会費だけでは足りない」と断定しないこと。** 「差額の出どころは公表資料から分からない」と書く。

出典: [部活動改革及び地域クラブ活動の推進等に関する総合的なガイドライン（文部科学省・令和7年12月）](https://www.mext.go.jp/sports/content/20251222-spt_oripara-000046180_00234.pdf)

**読み取れること**: 国自身が「ばらつきが出る」ことを前提に書いている。
ばらつきを禁じているのではなく、大きくならないようにと求めている。

## 5-2. 費用の実勢（笹川スポーツ財団）★第3回の背骨

出典: [中学生のスポーツ活動と保護者の関与に関する調査（速報値）2025年3月・公益財団法人笹川スポーツ財団](https://www.ssf.or.jp/files/jhs_and_parents_2024r.pdf)

- 対象: 「中学1～3年生の第1子をもつ保護者（母親・父親）」
- 有効回答数: **3,136**（母親1,586、父親1,550）
- 実施時期: **2025年1月**

### 年間費用（平均値）

| 活動 | 年間費用 |
|---|---|
| 文化部 | **13,866円** |
| 運動部 | **50,857円** |
| **地域スポーツクラブ** | **155,799円** |

- 運動部は「46.9%が10,001～50,000円」で5万円以下が7割
- 文化部は「40.5%が0円」で1万円以下が7割
- スポーツクラブは10万円以上が4割
- 非加入群では「費用の負担が大きく、運動やスポーツをさせることが難しい」が **34.1%**

### この数字の使い方（重要）

**部活 約5万円に対し、地域スポーツクラブは約15.6万円。およそ3倍。**

ただし調査の「スポーツクラブ」は民間のクラブチーム等であり、
**地域移行の受け皿である「認定地域クラブ」とは別物。同一視しないこと。**
「学校の外でスポーツをすると実際いくらかかっているか」の実勢として参照する。

そのうえで神栖市の会費は年25,000円（年1,000円＋月2,000円×12）で、
**運動部の平均50,857円よりも安い。**

→ 記事の結論はここから導ける。
**公費を入れれば部活より安くできる。入れなければ民間の価格に近づく。**
だから補助率（国1/3・都道府県1/3・市区町村1/3）を市区町村が出せるかどうかで、家庭の負担が決まる。

## 5-3. 困窮世帯への影響（認定NPO法人キッズドア）

出典: [2025「中学生の部活動と地域展開に関する調査結果報告」（認定NPO法人キッズドア・2026年5月15日公開）](https://kidsdoor.net/data/media/2025web.pdf)

- 対象: 「キッズドア・ファミリーサポート登録世帯」
- 回答数: **中学生のいる家庭738件**、小学生または中学生のいる家庭1,392件
- 実施時期: **2025年10月31日～11月10日**

| 設問・項目 | 数値 |
|---|---|
| 「地域移行（地域展開）によって、活動費用や送迎の面で、家庭の負担は増加したか」 | **8割**（とてもそう思う58%＋まあそう思う22%） |
| 困りごと「活動場所までの送迎が必要になること」 | **71%**（最多） |
| 困りごと「部費が高くなること」 | 67% |
| 困りごと「交通費が高くなること」 | 64% |
| 年間費用 | 5万円未満が約7割（1～3万円未満25%、3～5万円未満21%） |
| **「部活動をしていない」** | **所得100万円未満で39%、所得300万円以上で17%** |
| その理由「毎月の部費、交通費、大会参加費などが払えないから」 | 30% |
| その理由「ユニフォームや道具の購入など始めるための費用が払えないから」 | 29% |
| 「地域移行によって体験格差が拡大していく」と考える | **約9割**（とても55%＋まあ34%） |

**注意**: 対象は「キッズドア・ファミリーサポート登録世帯」＝支援を受けている困窮世帯。
一般世帯の調査ではない。記事では必ず**「困窮世帯を対象とした調査」と明記する。**

## 5-4. 使わない数字：「運動部 年8.4万円／保護者65%」

出典: [【中高生の部活費の実態調査】（ANYTEAM＝KDDI株式会社・スポーツブル株式会社）](https://prtimes.jp/main/html/rd/p/000000399.000018536.html)

- 調査主体: ANYTEAM（KDDI株式会社・スポーツブル株式会社）
- 方法: インターネット調査
- サンプル: 中高生214名、顧問100名、**保護者300名**
- 実施時期: 2026年6月26日〜30日
- 運動部 8.4万円／文化部 4.4万円／「負担」と感じた保護者 65.0%

**この数字は使わない。** 理由は2つ。

1. 民間企業の自社調査でサンプル300。笹川スポーツ財団（3,136）に比べて弱い
2. 同じ「運動部の年間費用」で 8.4万円 と 5.1万円 の2つの数字を並べると読者が混乱する

SNS投稿3件がこの報道を引用していたが、**記事では笹川の数字を採用する。**

## 8. 記事の骨になる構造

```
実証段階            本格実施
参加費0円     →     会費が発生
国の予算事業        国1/3・都道府県1/3・市区町村1/3
（2〜3億円）        （自治体が出せなければ家庭へ）

              ↓

    会費を下げれば、指導者が集まらない
    報酬を上げれば、家庭が払えない
```

**「安さの正体は、誰かが払っていなかったこと」**——第2回（先生の時間に値段がついていない）と、
第3回（値段をつけたら払える人がいない）が、一本の線でつながる。

## 8-2. パーセントの扱い（第2回のルールとの関係）

第2回で「率を使わず件数で書く」と決めたが、**それはSNS投稿の自前集計に対するルール**である。
理由は「世論調査ではないのに率で書くと世論の割合に読まれるから」。

**外部の調査の数値は、率のまま引用してよい。** むしろ件数に直すほうが不正確になる。

| 数字の出どころ | 書き方 |
|---|---|
| 自分たちのSNS集計（172件など） | **件数**で書く |
| 笹川スポーツ財団・キッズドアなど外部調査 | **率と金額**をそのまま引用し、調査名・対象・回答数を必ず添える |

この書き分け自体が、両者の性質の違いを読者に伝える装置になる。

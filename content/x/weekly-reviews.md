# X週次レビュー

X運用を表示数だけで判断せず、「価値 → 会話 → 学習」の循環を確認するための記録。
毎週1回、直近7日を同じ期間で集計する。取得できない項目は推測せず `未取得` と書く。

## 記入テンプレート

### YYYY-MM-DD〜YYYY-MM-DD

今週試した変数: 画像 / 冒頭 / 具体化 / 本文構造 / 締め方 / 形式 / 頻度 / 時間帯 / 投稿後対応 のうち1つ

| 観点 | 確認する値・内容 |
|---|---|
| 到達 | 投稿種別ごとの表示数、中央値、外れ値 |
| 会話 | 返信、引用、リポスト、どんな理由で反応されたか |
| 関心 | いいね、プロフィール訪問、フォロー（取得できる範囲） |
| 流入 | URL投稿のクリック、GA4のX流入、サイト内行動 |
| 再現条件 | 対象者、追加価値、冒頭、形式、画像、時間帯、投稿後対応 |

文章要素は、対象にした投稿だけを次の形で比べる。数字が少ないときは勝ち型と断定せず、
返信や共有が起きた理由を観察として残す。

| 投稿 | 冒頭の型 | 具体化 | 本文構造 | 締め方 | 観察できた反応 |
|---|---|---|---|---|---|
| URLまたはテーマ | 結論/場面/数字/ずれ/未解決/問い | 人物/行動/期限/比較/数字/例 | 主張→根拠/主張→例/観察→未解決 | 言い切り/判断基準/問い/読む理由 | 返信・引用・共有の内容 |

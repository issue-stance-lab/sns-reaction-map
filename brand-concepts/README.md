# ブランドアイコン第1段階

公開サイトを変更する前に、AI生成版とSVG版を同じ意味構造で比較するための候補です。

| 案 | AI生成版 | SVG版 | 特徴 |
|---|---|---|---|
| A 編集地図 | `ai/concept-a-editorial-map.png` | `svg/concept-a-editorial-map.svg` | 最も整然としており、編集部・データサイトの印象が強い |
| B やわらかな経路 | `ai/concept-b-soft-routes.png` | `svg/concept-b-soft-routes.svg` | 曲線でSNSの多様な声と流れを表す |
| C 問いの羅針盤 | `ai/concept-c-open-compass.png` | `svg/concept-c-open-compass.svg` | 中央の開いた4分割が最も明確で、小サイズに強い |

## 共通仕様

- 中央の白い開いた円: 答えを決めつけない「未解決の問い」
- 周囲の4色: 青・橙・緑・紫の4つの視点
- ネイビーの円形背景: Xの円形切り抜きとfaviconの両方に対応
- 人物、文字、既存キャラクター、円グラフは使用しない

## 生成方法

AI生成版はOpenAIの画像生成機能で作成した。編集部側で構想、プロンプト、選定条件を指定している。AI生成結果には指示に反してわずかな階調が含まれたため、最終採用時はSVG版を正本にするか、選定案をフラットカラーへ再調整する。

実際に使用したプロンプトは `PROMPTS.md` に記録している。

選定後にサイトロゴ、favicon、OGP、Xアイコン、Xヘッダーへ展開する。現時点では `docs/` 以下を変更していない。

部活動の地域展開：授業用資料

授業・探究学習で使う

授業・ディベートで使うとき

賛成・反対それぞれの理由を、まず3つずつ。メリット・デメリットを自分の言葉で書き出してから読み進めてください。

「移行支持」側の理由

  • 学校の部活動の会費が長く低く抑えられてきたのは、指導にあたる教員に指導料が上乗せされてこなかったからだ。指導を地域クラブや部活動指導員に委ねれば、教員は授業準備や生徒との面談に使える時間を取り戻せるという期待がある。 → 論点「教員の働き方」を見る

  • 部活動の指導が、必ずしもその競技の専門知識を持つ教員によって行われてきたとは限らない。地域移行の提言は指導者の質と量をともに確保する方策を独立した章で扱っており、認定を受けた地域クラブ活動では登録制度を通じた指導者が指導にあたる仕組みも用意されている。 → 論点「受け皿・指導者」を見る

  • 少子化で部員が集まらず、単独の学校では続けられない部活も少なくない。地域単位のクラブなら学校の垣根を越えて種目を維持できるため、生徒の選択肢を保てるという読み方につながる。 → 論点「教育的意義・機会」を見る

「慎重・反対」側の理由

  • 月々の部費のつもりで払ってきた家庭にとって、地域クラブの会費は同じ額では済まない可能性がある。指導者に対価を払う分だけ費用は上がる、と国の検討会議の提言自体が明記している。 → 論点「費用・家庭負担」を見る

  • 大会の参加費を自治体が肩代わりする地域もあれば、支援がなく家庭の持ち出しがそのまま残る地域もある。スポーツ庁次長自身が検討の場で地域間の差の大きさを認めていながら、国は一律の基準を設けない方針を取っている。 → 論点「地域格差」を見る

  • 部活動でのケガは学校の管理下として公的な災害共済給付の対象になってきたが、地域クラブの活動は学校の外の扱いになるため、この給付の対象から外れる。地域移行そのものを定めた法律も自治体に「努める」ことを求めるだけで、実施を義務づけてはいない。 → 論点「制度・移行プロセス」を見る

確かめる一次資料

  • スポーツ庁 運動部活動の地域移行に関する検討会議提言（令和4年6月6日・PDF）：地域に移ると会費が部費より上がる理由や、学校の管理下を離れると保険の仕組みが変わる背景を、政策の出発点になった提言本文で確かめられる。

  • スポーツ庁・文化庁 部活動改革の取組状況に関する調査（令和8年度調査・PDF）：休日と平日、都道府県ごとに地域クラブ活動への移行の進み方がどれだけ違うかを、国の調査結果そのもので確かめられる。

  • e-Gov法令検索 学校教育法施行規則 第七十八条の二：部活動指導員が中学校の技術指導に携わる法的な位置づけを、条文そのもので確かめられる。

問いの例

  • 中学校の部活動を、学校単位の運営から地域クラブ単位の運営へ移行すべきか。

  • 会費が上がる可能性を受け入れてでも、指導者に対価を払う地域クラブ活動を優先すべきか。

  • 大会に出るなら学校部活動か地域クラブ活動かを一つ選ばせる今の中体連の仕組みは、維持すべきか。

使い方

読む前に理由を書き出す→ページで確かめる→自分の理由と比べる。

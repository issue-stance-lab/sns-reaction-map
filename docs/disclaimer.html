本サイトは世論調査ではありません。

1. データの性質について

本サイトで表示される意見分布・分類結果は、Yahooリアルタイム検索から収集したSNS投稿のサンプル内の傾向です。統計的に厳密な世論調査ではなく、特定の時間帯・キーワードで取得した投稿をAIが分類したものです。

  • 表示件数は「世論の比率」を示すものではありません。
  • 検索クエリの選び方や収集時期によって、結果は大きく変わる可能性があります。
  • 同じトピックでも、再収集・再分類を行えば異なる分布になることがあります。

2. AI分類の限界

本サイトの分類はAIモデルを用いた自動処理です。使用するモデルや工程はテーマ・更新時期によって異なります。以下の限界があります。

  • 誤分類の可能性：皮肉や婉曲表現、文脈依存の投稿は正しく分類できないことがあります。
  • 「その他・分類保留」の存在：AIが判断に自信を持てない投稿は保留として扱われ、勢力図に含まれません。
  • 偏りの可能性：モデルの学習データに含まれるバイアスが、分類結果に影響を与える可能性があります。
  • 事実認定ではない：分類は「意見の整理」であり、投稿内容の真偽や適法性を保証するものではありません。

3. SNS投稿の引用ポリシー

本サイトでは、SNS投稿の全文をそのまま転載することを避け、以下の方針で扱っています。

  • 投稿内容は要約・リンク中心で表示します。
  • 「代表投稿」として掲載するものは、公開前に人間が確認しています。
  • 個人を特定できる情報（ユーザー名の完全表示など）は、必要に応じて加工しています。
  • 削除依頼や掲載に関するお問い合わせは、運営者情報・訂正窓口のお問い合わせフォームよりご連絡ください。

4. 投票機能について

各ページの投票機能は、サイト参加者が現在の考えを表明し、参加者内の集計を確認するためのものです。無作為抽出による調査ではなく、社会全体の意見分布を示しません。

  • 選択内容は投票済み状態の復元用にブラウザへ保存され、テーマと選択肢はSupabaseへ送信されます。投票日時はサーバー側で記録されます。
  • 同一接続元から同じテーマへの投票は、原則として24時間に1回までです。
  • 接続元IPアドレスはEdge Function内で秘密鍵付きの一方向変換を行い、IPアドレスそのものは投票データベースへ保存しません。詳しくはプライバシーポリシーをご確認ください。
  • 共有回線では別の利用者が重複と判定される場合があり、回線変更などにより重複防止が完全に機能しない場合もあります。
  • 画面上で選び直しても、24時間以内の再送はサーバー集計へ追加・上書きされません。
  • 通信障害、外部サービスの停止、保守作業などにより、投票や集計表示を利用できないことがあります。

6. 情報の正確性

本サイトに掲載されている情報には万全を期していますが、その正確性・完全性を保証するものではありません。掲載情報に基づいて行われた判断や行動について、運営者は一切の責任を負いません。

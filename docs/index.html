疑問ごとの解説記事

よく検索される疑問に1本ずつ答える記事です。制度で決まっていることと、SNSで意見が分かれている理由を分けて書きました。

交通・安全自転車の青切符導入
  • 青切符はおかしい？批判と賛成の理由批判の中心は、道が整う前に罰が来たこと
  • 歩道を走ると青切符？歩道を通っただけなら原則は指導警告。例外もあり
  • ヘルメットなしは青切符？着用は努力義務。かぶらないだけでは対象外
  • スマホ・イヤホン・傘差しは？ながらスマホは反則金12,000円、イヤホン・傘は5,000円
  • 自転車に免許制は必要？いまは免許不要。免許制は国の制度として決まっていない
教育・子ども部活動の地域移行
  • 親の費用負担はいくら？会費は月1,000〜3,000円程度が国の示すイメージ
  • 問題点は？なぜ進まない？国の調査では、平日の移行が休日より大きく遅れている
  • 反対・賛成の理由は？賛成は先生の働き方、反対は子どもの機会が中心
  • 市によってどう違う？神戸は平日も休日も移行、名古屋は休日から
  • コベカツとは？神戸市の部活動は2026年9月から地域クラブへ
交通・福祉高齢者の運転免許返納
  • 免許返納は義務化すべき？いまは義務ではない。賛否は論点で分かれる
  • 親が返納を拒否したら？理由を聞き、返納後の足を一緒に決める。相談は#8080
  • 運転経歴証明書とは？返納から5年未満で申請。本人確認書類になる
  • 田舎で返納したら移動は？バスやデマンド交通など。何があるかは自治体しだい
  • サポカー限定免許とは？安全機能付きの車だけ運転できる条件付きの免許

HOW IT WORKS

たくさんの声から、見えてくるものがある。

SNSにあふれるさまざまな意見を集め、AIと人の目で論点ごとに整理。賛成と反対だけでは見えない、考え方の広がりを可視化します。

01COLLECT VOICES

社会のあちこちにある声を集める。

ニュースやSNSで交わされている公開投稿を、テーマごとに集めます。特定の立場に偏らないよう、さまざまな言葉と視点から声を探すのが決まりです。

02ORGANIZE WITH AI

AIと人の目で、論点をほどく。

集めた投稿をAIが分類し、人が内容を確かめます。ポジティブ・ネガティブの二分ではなく、「何について、どう考えているか」の整理です。

03MAP THE STANCES

賛否の間にある、考え方まで見える。

意見を4つの立場に分けて表示。数字だけでなく、代表的な主張と背景にある論点も一緒に読めます。

賛成・推進反対・慎重条件付き中立・保留
04JOIN THE MAP

あなたの考えも、地図のひとつに。

テーマを読んだら、あなたの考えに近い選択肢へ投票できます。誰かを言い負かすためではなく、考え方の広がりを一緒に見つけるための投票です。

このサイトの読み方

  1. 疑問に近いテーマを選ぶ
  2. 制度で決まっていることを確かめる
  3. 賛成・反対それぞれの理由を読む
  4. 自分と遠い意見も1つ読んで、一次情報を確認する

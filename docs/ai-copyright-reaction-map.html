何が、どこまで進んでいるのか

官庁の資料で確かめた範囲

生成AIと著作権の問題は、AIが文章・画像・音楽などを学習したり作り出したりする際に、既存の著作物をどこまで無断で使ってよいかという論点です。著作権法第30条の4は、著作物を「思想又は感情の享受を目的としない」利用であれば、原則として権利者の許諾なく使えると定めています。

著作権法そのものは変わっていません。政府がまとめてきたのは、この条文をどう解釈するかという「考え方」と、AI事業者に情報開示を求める任意のルール「プリンシプル・コード」までで、法律の改正には至っていません。

なぜ始まったか

生成AIの急速な普及に伴い、既存の著作物が無断でAIの学習に利用されているのではないかという懸念がクリエイターや権利者団体から強まりました。一方でAI開発・提供事業者からは、学習段階の利用を過度に制限すると技術革新や国際競争力が損なわれるとの声もあり、権利者・事業者・利用者それぞれの立場から議論が続いています。

文化庁と内閣府が別々に検討を進めてきました。文化庁は既存の著作権法（特に第30条の4）の解釈を整理し、内閣府の検討会はAI法の制定や、AI事業者に学習データの出所開示を求める任意ルール「プリンシプル・コード」づくりを進めています。どちらも著作権法そのものを書き換えるものではありません。

これまでの経緯

  1. 2024年3月15日文化庁が学習段階の考え方を公表

    文化審議会著作権分科会が、AIの学習段階での著作物利用について著作権法第30条の4の適用範囲を整理し公表しました。学習のための利用は原則対象外ですが、学習データの創作的表現をそのまま出力させる目的が併存する場合などは対象外になりうるとしています。

    出典: 文化庁「AIと著作権に関する考え方について」（令和6年3月15日）
  2. 2024年5月内閣府検討会が中間とりまとめを公表

    内閣府「AI時代の知的財産権検討会」が、開発・学習段階と生成・利用段階に分けて著作権法上の課題を整理した中間とりまとめを公表しました。

    出典: 内閣府「AI時代の知的財産権検討会 中間とりまとめ」（2024年5月）
  3. 2025年6月4日AI法が公布

    AI技術全般の研究開発・活用を推進する法律（AI法）が公布されました。著作権法とは別の法律で、この後まとまる「プリンシプル・コード」の根拠になっています。

    出典: e-Gov法令検索「人工知能関連技術の研究開発及び活用の推進に関する法律」（令和七年法律第五十三号、2025年6月4日公布）
  4. 2025年12月12日「プリンシプル・コード」案が固まる

    内閣府検討会（第10回）で、AI事業者に学習データの出所などの開示を求める「プリンシプル・コード」案が事務局から示されました。開示は義務ではありません。実施するか、しない場合は理由を説明する「コンプライ・オア・エクスプレイン」方式が採られており、この後パブリックコメントにかけられました。

    出典: 内閣府「AI時代の知的財産権検討会」第10回議事録（2025年12月12日開催）
  5. 2026年4月21日・23日パブリックコメント結果を公表、関係団体にヒアリング

    プリンシプル・コード案に寄せられた2,161件の意見（うち法人・団体99件）が報告されました。新聞・出版・放送・音楽の権利者団体は開示義務の強化を求め、AI事業者側の業界団体（BSA）は開示義務そのものに反対するなど、意見が分かれています。

    出典: 内閣府「AI時代の知的財産権検討会」第12回議事録（2026年4月23日開催）／同 第11回議事録（2026年4月21日開催）
  6. 2026年6月「知的財産推進計画2026」を決定

    政府の知的財産推進計画に、著作権法の対象外である声・作風の模倣についてパブリシティ権や不正競争防止法での対応を「引き続き議論」する方針と、プリンシプル・コードの普及を進める方針が盛り込まれました。いずれも具体的な法改正は伴っていません。一次資料で確認できた範囲では、これが最も新しい動きです。

    出典: 内閣府「知的財産推進計画2026」（2026年6月決定）

「法律」と「任意のルール」を分けて確かめる

著作権法・その解釈・自主ルールを混同しない

生成AIと著作権をめぐっては、著作権法そのものと、その解釈を示した「考え方」、AI事業者向けの任意ルール「プリンシプル・コード」が並行して存在します。どれについての話かを区別しないと、賛否の理由がかみ合わなくなります。

AI学習と著作権侵害「無断学習」は一律に違法なのか
一律には決まっていません。著作権法第30条の4により学習のための利用は原則として権利者の許諾が不要ですが、学習データの創作的表現をそのまま出力させる目的が併存する場合などは対象外になりうるという考え方が文化庁から示されています。個別の裁判例の蓄積はまだありません。出典: 文化庁「AIと著作権に関する考え方について」（令和6年3月15日）／e-Gov 著作権法 第30条の4
学習データの情報開示AI事業者は出所を明かす義務があるのか
義務ではありません。政府が示した「プリンシプル・コード」は、開示するか、開示しない場合はその理由を説明する「コンプライ・オア・エクスプレイン」方式の任意ルールで、法律による強制ではありません。出典: 内閣府「生成AIの適切な利活用等に向けた知的財産の保護及び透明性に関するプリンシプル・コード」
2026年の著作権法改正SNSで話題の「著作権法改正」とAI学習の関係
無関係です。令和8年の著作権法改正は実演家の二次使用料に関するもので、AI学習の適法性に関わる第30条の4・第47条の5は改正されていません。出典: 文化庁「著作権法の一部を改正する法律」（令和8年法律第48号）改正ページ
声・作風の保護似せて作られた声や画風への対応
方針だけが示されています。声の模倣についてはパブリシティ権や不正競争防止法での対応を「引き続き議論」するとされていますが、著作権法によって声や作風そのものを保護する規定はまだありません。出典: 内閣府「知的財産推進計画2026」（2026年6月決定）／第221回国会 参議院 文教科学委員会 第11号（令和8年6月16日、谷合正明君発言）

このページで未確認のこと
AI生成物の著作権を直接扱った日本の確定判例は確認できていません。プリンシプル・コードの届出（コンプライ・オア・エクスプレイン）を実際に行った事業者の一覧も、本資料確認では確かめられていません。
「違法」か「合法」かという二択で判断せず、確定した法律の条文なのか、その解釈を示した考え方なのか、事業者の任意ルールなのかを区別して読む必要があります。

    授業・ディベートで使うとき

    賛成・反対それぞれの理由を、まず3つずつ。メリット・デメリットを自分の言葉で書き出してから読み進めてください。

    「推進・活用支持」側の理由

    • 著作権法第30条の4は、鑑賞して楽しむこと自体を目的としない利用であれば、その必要な範囲でAI学習に使ってよいという立て付けになっている。学習した結果を誰かが鑑賞目的で使ったとしても、学習という行為自体が直ちに違法になるとは限らない。 → 論点「学習データ・無断利用」を見る

    • 政府は「世界で最もAIを開発・活用しやすい国」を目標に掲げている。学習や活用の場面に慎重すぎるルールを重ねれば、掲げた目標そのものと矛盾しかねない、という立場になる。 → 論点「技術競争・推進」を見る

    • 生成AIを下描きや構成のたたき台として使い、そこに人の手で試行錯誤を重ねて作品に仕上げるクリエイターもいる。そうした作品まで一律に「AI製だから保護されない」と扱われれば、人の創作的寄与そのものが評価されなくなる。 → 論点「AI生成物の権利・創作性」を見る

    「規制・制限強化支持」側の理由

    • 著作権法には声そのものを直接保護する規定がなく、対抗できるパブリシティ権にも著名性という高いハードルがある。若手や中堅の実演家ほど、無断でAIに声を模倣されても法的な後ろ盾を持ちにくい。 → 論点「クリエイター保護・権利」を見る

    • 学習データの出所開示を求めるプリンシプル・コードは、事業者が実施しない場合に理由を説明すれば足りる任意の枠組みにとどまる。日本新聞協会などはこの状態を踏まえ、応じない事業者には法制化の検討まで政府に求めている。 → 論点「法制度・規制整備」を見る

    • 日常的に生成AIへ触れている学生ほど、著作権法上どこまでが利用者の責任になるのかを教わる機会がまだ乏しい。国会でも知財教育の強化が必要だという指摘が出ており、モラルは自然に身につくと期待するだけでは足りないという考え方につながる。 → 論点「利用者モラル・倫理」を見る

    確かめる一次資料

    • 文化庁「AIと著作権に関する考え方について」（文化審議会著作権分科会法制度小委員会、令和6年3月15日）：AI開発・学習段階での著作物利用について、権利者・事業者・利用者それぞれの懸念と、著作権侵害になりうる場合の線引きを確かめられる。

    • e-Gov法令検索（デジタル庁）著作権法 第30条の4：AI学習が原則として著作権者の許諾なく行える根拠となる条文と、権利者の利益を不当に害する場合は適用されないというただし書きを確かめられる。

    • 内閣府知的財産戦略推進事務局「生成AIの適切な利活用等に向けた知的財産の保護及び透明性に関するプリンシプル・コード」：学習データの出所開示等を事業者に求める現行の枠組みが、実施しない場合は理由の説明で足りる任意の「コンプライ・オア・エクスプレイン」にとどまっていることを確かめられる。

    判断の入口

    学習・出力・公開――どの行為にルールを求めるか

    生成AIをめぐる著作権の問題は、「学習に使うとき」「画像や文章を作るとき」「公開・販売するとき」で、考えるポイントが変わります。まず、いま気になっているのがどの場面かを確かめてください。

    1. 学習データの収集・学習

      著作物の表現を楽しませる目的がない情報解析には、30条の4が適用され得ます。一方、目的や収集方法など個別事情で見方が変わります。

      （「学習なら常に合法」と断定するものではありません。）

    2. 生成

      特定の作品に似た出力を生む場合、どの表現が共通しているか、どのように生成されたかを区別して考える必要があります。

      （このページは、個別の生成物が著作権侵害に当たるかを判断するものではありません。）

    3. 公開・販売

      生成物を公開・販売する段階では、既存著作物との類似性と依拠性が認められるかが問題となり得ます。

      （最終的な評価は、個別の事情を踏まえて裁判所が判断します。）

画像制作方針

SNS反応まっぷに掲載するAI生成画像の用途、制作・確認方法、ご指摘への対応について

1. AI生成画像を使用しています

SNS反応まっぷでは、文字だけでは伝わりにくい論点やページの雰囲気を視覚的に表すため、OpenAIの画像生成機能を使用しています。AIが自動的にサイトへ掲載するのではなく、SNS反応まっぷ編集部が企画、指示、選定、加工、内容確認を行っています。

2. 使用している箇所

AI生成画像は、主に次の用途で使用しています。

  • トップページ（index）のイメージ画像
  • 各テーマのヘッダー・ヒーロー画像
  • 論点を説明するインフォグラフィック
  • 一部テーマの投票画像・漫画画像

グラフ、件数、投稿分類などのデータ表示は、画像ではなく公開データとページ内の処理から作成しています。

3. 制作と確認の流れ

  1. 編集部が、テーマと画像の役割に合わせて構成と生成指示を作ります。
  2. OpenAIの画像生成機能で候補画像を作ります。
  3. 編集部が候補を選び、必要に応じてトリミング、リサイズ、形式変換などを行います。
  4. 掲載前に、内容の誤り、不自然な文字、実在人物やロゴとの混同、既存作品との目立った類似がないかを確認します。

4. 生成時に避けるもの

画像生成の指示では、次のような指定を行わない方針です。

  • 特定の作家・イラストレーターの名前や作風を指定すること
  • 既存の漫画、アニメ、映画、ゲームなどの作品名を指定して模倣させること
  • 著作権のあるキャラクターや第三者のロゴを登場させること
  • 実在人物を、本人の写真と誤解される形で描くこと

5. AI生成画像の限界

AI生成画像であることだけを理由に、著作権上の安全性や第三者の権利を侵害していないことが自動的に保証されるわけではありません。また、生成画像に対して本サイトが独占的な権利を持つことを保証するものでもありません。

既存作品との類似性や権利上の問題は、画像ごとの具体的な内容に基づいて確認します。問題が判明した場合は、必要に応じて一時的な非表示、修正、差し替えまたは削除を検討します。

6. 画像に関するご指摘

掲載画像について、既存作品との類似、権利侵害のおそれ、実在人物・団体に関する問題などにお気づきの場合は、お問い合わせフォームから該当ページと理由をお知らせください。内容を確認し、必要に応じて一時的な非表示、修正または削除を行います。個人運営のため、確認・対応期限は設けていません。

フォームでは、お問い合わせ種別の「画像・著作権等に関するご指摘」を選択してください。

お問い合わせ内容には、分かる範囲で次の情報をご記載ください。

  • 該当ページまたは画像のURL
  • 問題だと考える理由
  • 類似する元作品などがある場合は、その参考URL
  • 希望する対応（確認、修正、削除など）

最初のご連絡で、権利者であることの証明や個人情報の提出は必須ではありません。返信を希望する場合のみ、フォームへメールアドレスをご記載ください。

7. ご指摘を受けた場合

具体的な元作品、実在人物、ロゴ、個人情報などが示され、問題の可能性が高い場合は、確認中に画像を一時的に非表示にすることがあります。「雰囲気が似ている」というご指摘については、構図、人物、固有の表現などの具体的な共通点を確認します。

確認後は、掲載継続、修正、差し替え、削除のいずれかを判断します。法的な判断が必要な場合は本サイトだけで断定せず、公開停止や専門家への相談を検討します。返信先があり、権利関係について具体的なご申告があった場合は、可能な範囲で確認結果をお知らせします。

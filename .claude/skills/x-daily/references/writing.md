# X投稿の文章作成と推敲

リプライ、論点ポスト、URL付き流入投稿の共通基準として使う。
候補選定、投稿枠、UTM、計測は `../SKILL.md` と `X_POSTING_GUIDE.md` に従う。

## 文章の到達点

次を同時に満たす文章にする。

- 誰に向けた何の話かを1行目で示す
- 1投稿1主張に絞る
- 抽象的な評価ではなく、場面・行動・数字・比較・根拠を渡す
- 強い賛否を押し付けず、読者が自分で判断できる余白を残す
- 説明書や講義ではなく、具体的な一人に話す自然な声にする

## 作成手順

### 1. 設計を4行で固定する

文面の前に次を1つずつ書く。

- **対象者**: 状況まで絞った一人
- **目的**: 認知、会話、プロフィール形成、サイト流入のどれか1つ
- **追加価値**: 事実、区別、判断基準、具体例、未解決点のどれか
- **1つの主張**: 読後に何を1つ覚えてほしいか

対象者を「社会問題に関心がある人」で止めない。例えば「部活動の地域移行で、
子どもの活動機会と保護者負担の両方を心配する人」まで絞る。

### 2. 冒頭を異なる3方向で作る

内容に合う3種類を下から選び、内部で比較する。利用者には原則として採用案だけを示す。

- **結論**: 最も大事な観察や判断基準を先に置く
- **具体的な場面**: 読者が生活や仕事で見る状況から始める
- **数字＋期間**: 何を数えた数字か分かる形で置く
- **前提のずれ**: 似ているが異なる2つの問いを示す
- **未解決点**: 分かっていない対象を具体的に示す
- **問い**: 本文で答えや判断材料を返せる場合だけ使う

冒頭は、本文が実際に返す価値を約束する。「衝撃」「意外」など、本文以上の期待を作らない。

### 3. 主張の直後に具体性を置く

主張の後を一般論で続けず、次のどれかを置く。

- 出典を確認できる根拠
- 主張の意味が同じ像として浮かぶ具体例1つ
- 過去の自分、別形式、別期間などの比較対象
- 「この資料で確認できる範囲」などの観測範囲

抽象語を見つけたら、次から2つ程度を足す。全てを詰め込まない。

- 誰が困る、得をする、決めるのか
- 何を変える、比べる、確認するのか
- いつ、どこで起きるのか
- どの行動、変化、制約が問題なのか
- 費用、責任、期限、確認方法を誰が持つのか

複数の判断軸が見つかっても、本文へ並列に詰め込まない。主張を支える最も強い1つを選び、
残りは画像、別投稿、会話の続きへ回す。複数の軸そのものを比較する投稿の場合だけ、必要最小限の並列を認める。
URLなしリプライでは、元投稿へ足す判断基準を原則1つにする。画像を使えない場合も、
画像に入っていた複数の軸を本文へ詰め戻さず、最も強い1つを残す。

「分かりやすい」「大切」「多い」「大変」「伸びる」と評価する代わりに、何がどうなるかを書く。

数字は単独で置かず、必ず次の形にする。

> 数字＋何を数えたか＋期間・比較・出典のどれか

数字にできない場合は無理に作らず、「確認できた範囲」を書く。

### 4. 締め方を目的に合わせる

次のどれか1つで終える。

- 主張や観察を言い切る
- 読者が自分の状況で使える判断基準を渡す
- 経験や判断基準から具体的に答えられる問いを1つ置く
- URL付き投稿で、リンク先で何を確認できるかを示す

「あなたはどう思いますか」とテーマ全体の感想を求めない。

### 5. 文体を整える

- 意味のまとまりごとに2〜3ブロックへ分ける。1文ごとの過剰な改行は避ける
- 事実、観察、判断、限界を書き分け、同じ語尾を繰り返さない
- 絵文字、記号、強調語を根拠の代わりに使わない
- 「AではなくB」「AとBは別」「分けて考える」を便利な定型として連用しない
- 直近3本の冒頭、語尾、本文構造、対比表現を見て、似た形を避ける
- 強い賛否を代弁せず、分からないことは分からないまま書く
- 元投稿、当事者、事故、遺族への敬意を保つ

### 6. 仕上げる

1. 前置き、重複、強調語、なくても意味が変わらない副詞を削る。20〜30%は目安であり必須率にしない
2. 声に出して読むつもりで、詰まる長文、主語不明、硬い表現を直す
3. X換算を280以内にする。文字数を減らすときも主張と根拠は残す
4. 数字、因果関係、出典、強い断定を事実確認する
5. 最終文を1文で要約し、主張が1つに絞れているか確認する
6. 直近3本にある「AとBは別」「分けて考える」などを再利用していたら、場面・人・行動で言い換えられないか検討する
7. 画像を使う場合は、画像内の重要な文字と何を示す図かが分かる代替テキストを作る

## 例

抽象的で論点が多い文章:

> 減税を実施するなら、家計への効果、事業者の負担、失われる税収を検証する必要があります。

場面と1つの判断基準に絞った文章:

> 食料品の消費税を下げても、レシートの金額が同じなら、家計支援になったとは言い切れません。
>
> まず確認したいのは、減税分が店頭価格へ反映されたかどうかです。

## 固定ルールにしないこと

次は下書きや検証の出発点として使い、伸びる保証として扱わない。

- 特定の冒頭型、単語、文字数が必ず伸びる
- 疑問形で終えると必ず返信が増える
- 数字や画像を入れると必ず信頼や到達が増える
- 2〜3ブロック、20〜30%の削減が全投稿の最適値になる

効果は自アカウントの投稿で測る。週ごとに変える文章要素を1つに限る。

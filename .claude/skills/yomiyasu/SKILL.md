# よみやす — SNS反応まっぷ版

公開文章は、依頼に明記されていなくてもこのスキルを通す。AIが初稿を書いてから機械的に全置換するのではなく、最初からよみやすの基準で書き、保存前に差分とリンターで漏れを確認する。

## 優先順位

1. 原文・一次資料の意味、数字、出典、URL、引用、断定の強さを保持する。
2. `upstream/SKILL.md` のよみやす規則を適用する。
3. `references/sns-reaction-map.md` の媒体別ルールと公開条件を守る。
4. `WRITING_VOICE.md` のうち上記と競合しない規則を適用する。

文体が競合した場合はよみやすを優先する。事実や主張が動く場合は表現を変えない。

## 実行

1. `upstream/SKILL.md` を全文読む。
2. noteまたはXなら、同スキルから案内される該当ドメイン参照も読む。
3. `references/sns-reaction-map.md` を読み、対象媒体と保護対象を確認する。
4. よみやす基準で初稿を作るか、既存稿を推敲する。
5. 保存前に次を実行する。

```bash
python3 scripts/review_with_yomiyasu.py <対象ファイル> --medium <note|website|seo|x> --strict
```

既存稿を書き換えた場合は、変更前のコピーも渡す。

```bash
python3 scripts/review_with_yomiyasu.py <変更後> --original <変更前> --medium <note|website|seo|x> --strict
```

機械で止まる項目と目視で確認する項目の一覧は、`references/sns-reaction-map.md` の「機械で止まる項目と目視で確認する項目」にある。上流のリンターはダッシュ記号、1文の読点、文の長さを見ないので、これはスクリプト側で止めている。出力の「文の長さ」の行で、平均が30〜45字の目安に近いかを人が確かめる。

6. よみやす検査のあと、媒体固有の検査と `python3 scripts/verify_ai_tone.py` を実行する。

警告が残った場合は最大2回まで見直す。数字・出典・URL・必要な否定対比を守るために残した指摘は、消すためだけに言い換えず、納品時に理由を報告する。

## 対象外

調査メモ、運用記録、設計書、タスク管理、プロンプト、画像生成指示、コードとコメントは通常対象外。公開文章がファイルの一部にある場合は、公開される本文だけを検査する。

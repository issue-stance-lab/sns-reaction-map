# SNS反応まっぷ固有ルール

## 変更してはいけないもの

- SNS投稿サンプルを世論と書き換えない。
- 数字、単位、日付、固有名詞、出典名、URL、UTMパラメータを変えない。
- 事実、SNS上の意見、編集部の評価、推測を混ぜない。
- 推量を断定へ強めず、断定を推量へ弱めない。
- 賛否どちらかを愚かに描かない。双方が守ろうとしているものを残す。
- 「無作為抽出の世論調査ではなく、SNS公開投稿のサンプル分析」のような、母集団の限界を示す否定は残す。
- 公開文に内部ペルソナの名前や経歴を出さない。

## よみやすを優先する項目

- 平均文長は30〜45字を目安にする。長いことだけを理由に分割しない。
- 読点は1文0〜2個を目安にする。
- 絵文字、em dash、文末コロンを公開本文に使わない。
- CTAは絵文字ではなく、リンク先で分かることを平文で示す。
- 同じ文末が3回以上続く場合は、意味と文の働きを変えずに整える。
- 不自然な非生物主語、比喩動詞、空疎な前置き、意味を担わない否定対比を直す。

## 媒体別

### note

`*-FINAL.md` と `*-CANDIDATE.md` は、最初の区切り線 `---` より後を公開本文として検査する。区切り線より前の作業メモ、画像プロンプト、チェックリストは対象外。記事の主張、反論、根拠、結論の比重を変えない。

### Website・SEO記事

WebsiteのHTMLは、共通UI、免責、フッター、スクリプトを除いた編集本文を検査する。生成物を直接直さず、発注書・設定・adapterなど再生成元を直す。

### X

280字制限と1投稿1主張を優先する。平均文長は投稿全体の合否条件にしないが、主語不明、過剰な読点、絵文字、比喩、定型の対比は直す。投稿操作は行わず、候補だけを作る。

## 判定

`warn` と `error` は完成を止める。`info` は内容を確認するが、必要な否定対比なら残してよい。リンタースコアを上げるために意味を削ったり、新しい説明を足したりしない。

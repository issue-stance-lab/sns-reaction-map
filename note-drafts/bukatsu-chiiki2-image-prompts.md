## 0. 共通仕様（最初にこれを渡してから、各図のプロンプトを渡す）

```
これから note 記事用の画像を4点つくります。まず共通仕様を渡します。
以降の指示はすべてこの共通仕様に従ってください。

## いちばん重要なルール（第2回で新しく加わりました）

図にも本文にも、パーセントを一切書きません。数字はすべて「件」です。

理由：このサイトは「世論調査ではない」と明記しています。
率で見せると「日本人の何割が」と読まれてしまいます。
しかも今回の87件は編集部が手で読み分けたものなので、
小数の割合を出すと精度を偽ることになります。

- 軸の目盛も、凡例も、ラベルも、すべて「件」
- 帯グラフでも、区分の中に率を書かない
- 程度は「半分以上」「いちばん多い」と言葉で表す
- 率を使ってよいのは第1回だけです。第2回以降は件数で通します

この指示に反する図を作らないでください。迷ったら件数を出してください。

## 方式
人物・情景の写真は生成し、その上に HTML/CSS で数字・ラベル・グラフを重ねます。
写真そのものを加工したり、文字を画像として生成したりはしないでください。

## 実装方法
- 1画像 = 1つの自己完結したHTMLファイル（CSSはインライン、外部JSなし）
- 写真は <img> または background-image で読み込む
- レンダリングは Playwright（Chromium）で該当要素をスクリーンショットしてPNG化
- フォントは Google Fonts の Noto Sans JP（weight 400/500/700/900）
- 数字には font-variant-numeric: tabular-nums を必ず指定
- 写真入力: note-drafts/photos/
- HTML出力: note-drafts/figures/<名前>.html
- PNG出力:  note-drafts/images/<名前>.png
- note-drafts/figures/render2.mjs にまとめ、4点を一括再生成できるようにする
  （第1回の render.mjs は上書きしないこと）

## カラートークン（既存のSNS反応まっぷのテーマ。変更しないこと）
--page:    #07111E
--card-1:  #0C1E35
--card-2:  #0A1928
--card-3:  #071522
--ink:     #F0F4FF
--ink-70:  rgba(240,244,255,0.70)
--ink-45:  rgba(240,244,255,0.45)
--teal:    #2DD4BF   /* 主役アクセント／移行支持 */
--red:     #F87171   /* 慎重・反対 */
--amber:   #FBBF24   /* 条件付き・改善要求 */
--gray:    #64748B   /* 中立・情報／その他 */

カード共通スタイル:
- background: linear-gradient(145deg, var(--card-1) 0%, var(--card-2) 60%, var(--card-3) 100%)
- border: 1px solid rgba(255,255,255,0.08)
- border-radius: 16px
- 48px間隔の微細グリッドテクスチャ: rgba(255,255,255,0.025) の1px線を縦横に
- 右上に teal のごく淡いグロー: radial-gradient(circle, rgba(45,212,191,0.12) 0%, transparent 70%)
- 右下に小さく「SNS反応まっぷ」（12px, --ink-45, letter-spacing .08em）

## 写真の上に文字を置くときの必須処理（「ざぶとん」）
四角い半透明パネルは使わないでください。人物の顔にかかると目隠しに見えます。
必ず線形グラデーションを使います。
  linear-gradient(90deg, rgba(7,17,30,0.94) 0%, rgba(7,17,30,0.86) 42%,
                  rgba(7,17,30,0.15) 72%, rgba(7,17,30,0) 100%)
そのうえで実際のコントラスト比を計算し、大きな文字（24px以上）は3:1以上、
小さな文字は4.5:1以上を満たすことを確認して報告してください。
写真は場所によって明るさが変わるので、最も明るい画素を基準に判定します。

## グラフ作図のルール（厳守）
1. 塗り面どうしは必ず 2px の隙間を空ける（背景色で抜く）
2. データ端の角丸は 4px。ベースライン側は角を丸めない
3. 目盛線・軸線は控えめに（rgba(255,255,255,0.06) 以下、1px）
4. 数値ラベルは棒の中か直後に直接置く
5. 系列が2つ以上あるときは凡例を置く。1系列なら凡例なし
6. 棒の起点と軸の 0 の位置を必ず一致させる
7. 数値・ラベルのテキストは白系トークンで書く。系列色をテキストに使わない
8. 2軸グラフは禁止
9. 情報を詰め込まない。余白を十分に取る
10. コンテンツの高さに合わせてキャンバス高さを詰める（下部に大きな空白を残さない）

## 検収（各図つくるたびに必ず）
- PNGを実際に開いて目視し、ラベルの重なり・はみ出し・切れがないか確認する
- 幅375pxに縮小した状態でも主要な数字が読めるか確認する
- 写真の上の文字のコントラスト比を計算して報告する
- パーセント表記が1つも入っていないことを確認する
- 何をどう直したかを具体的に報告する

質問があれば聞いてください。なければ「了解」とだけ返してください。
```

## 付記1｜第1回から変えたこと・変えないこと

| | |
|---|---|
| **変えない** | 配色トークン、カードスタイル、フォント、作図ルール、写真のスタイル・ロック、中央正方形の制約 |
| **変える** | **数値の単位を「件」に統一（パーセント全面禁止）**、見出し画像の主役を数字1つに、図3として表形式の図を新設 |

シリーズとして並べたとき、**第1回だけが率で、第2回以降は件数**という構図になります。
これは意図した設計です。第1回の主張（率は当てにならない）が、シリーズの見た目にも表れます。

## 付記2｜配色の検査結果（第1回から引き継ぎ）

既存テーマのパレットは、標準的な検査で次の結果でした。

| 検査項目 | 結果 |
|---|---|
| 色覚多様性での識別（隣接ペア） | PASS |
| 通常視力での識別 | PASS |
| 背景とのコントラスト | PASS（4色すべて 3:1 以上） |
| 明度バンド | FAIL（暗い背景に対して明るすぎる） |
| 彩度の下限 | FAIL（#64748B が灰色に見える） |

2つのFAILは既存テーマの設計そのもの／意図どおりのグレーなので許容します。
